# v3.13.0 — 增强对比分析（Phase 7）

> **日期**：2026-08-16 ｜ **类型**：⚡ 新功能 —— 习惯总结 / 消费趋势 / 个性化建议

## 背景

Phase 5 让晓风能**对比**数据（本周 vs 上周、分类统计），但数据洞察仍停在"已经发生什么"。
Phase 7 在 Phase 5 的基础上补上三个**前瞻性**能力：把历史轨迹沉淀成**习惯**、读出支出的**走向**、
并基于消费模式给出**可执行的建议**——让数据从"记录"升级为"指导"。

## 新增功能

| # | 功能 | 触发示例 | 输出示例 |
|---|------|----------|----------|
| 1 | 习惯总结 | 我最近有什么习惯 | 1. 喝咖啡（31次，刚形成） 2. 吃饭（18次…）4. 喝水（5次，已持续7周）… 你最近的习惯有：喝咖啡、吃饭、购物… |
| 2 | 消费趋势 | 最近消费趋势怎么样 | 最近3周消费趋势：7-27周257元、8-3周95元、本周233元；最近3周支出保持平稳（257元→233元）；主要支出集中在生活（143元） |
| 3 | 个性化建议 | 有什么建议给我 | 1. 可以考虑自己做饭：最近外出/外卖就餐较多（约4次/周），每月可节省约74元 |

无数据/数据不足时统一友好提示：**「数据太少，暂时分析不出消费趋势」** 等。

## 变更内容

### `记忆引擎.py` — 新增 Phase 7 分析函数（约 230 行）

新增函数：
- `get_habit_summary(limit=5)` — 习惯总结
  - 数据源 1：`patterns.json` 行为模式（content + frequency + `created_at` 持续时长）
  - 数据源 2：`get_frequent_activities()` 高频活动（记忆实体标签 + 财务来源 + 对话归档）
  - 同内容习惯合并频次；按频次降序；`_habit_duration_text` 把持续时长格式化为「已持续N天 / N周（≥2周显示周）」
  - **排除非行为类标签** `_HABIT_EXCLUDE = {"情绪", "聊天"}`（情绪是情绪记忆的标签，不是行为习惯）
- `analyze_spending_trend(periods=3)` — 消费趋势
  - 按周聚合支出（`_week_start_date` 周一为一周起点），取最近 `periods` 个时段
  - 数据不足两周自动降级按月聚合
  - 方向判定：首尾变化 **±10%** → rising/falling/stable（`direction_cn` 上升/下降/平稳）
  - 洞察：逐分类对比最近时段 vs 前段均值，识别**涨幅最大**的支出分类（rising 时提示"建议关注"）
- `get_personalized_recommendations()` — 个性化建议
  - 近 30 天支出按 分类+来源 命中规则：咖啡→自制咖啡（约省60%）、外卖/饭→自己做饭（约省30%）、交通→公共交通（约省50%）
  - 每条建议含 **suggestion + reason + benefit**（估算每月可节省金额）
  - 无命中分类时兜底「每周设定消费预算」建议

`run_analysis` 新增三个分发分支（置于消费语境检测之前，优先级高于 Phase 5 分支）：
- `习惯` → `get_habit_summary()`
- `趋势/走势/走向` → `analyze_spending_trend()`
- `建议/怎么省钱/如何省钱/省钱` → `get_personalized_recommendations()`
