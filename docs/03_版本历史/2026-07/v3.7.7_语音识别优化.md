# v3.7.7 — 语音识别模块优化

**日期**：2026-07-15  
**类型**：增强 (enhancement)  
**影响范围**：`00_核心主体/器官/耳朵.py` — 全部录音后端 + 后处理管线

## 变更动机

v3.7.2 的语音识别存在以下问题：
- **固定 VAD 阈值**：安静环境和嘈杂环境使用同一个 `SILENCE_THRESHOLD = 500`，导致安静时漏检、嘈杂时误触发
- **无增益控制**：说话音量波动大时，VAD 和 Vosk 识别率都不稳定
- **无后处理纠错**：Vosk 常见的误识别（如"教"→应为"叫"）未修正
- **无语音时无法提前中止**：用户点了语音输入但没说话，系统一直等到 MAX_RECORD_SECONDS

## 变更内容

### 1. 动态 VAD 阈值校准

录音前 0.3 秒用于测量环境噪声 RMS：

```
noise_floor = avg(RMS[0:0.3s])
vad_threshold = max(noise_floor × 2.5, 100)
```

| 环境 | noise_floor | 旧阈值 | 新阈值 | 效果 |
|------|-------------|--------|--------|------|
| 安静室内 | ~50 | 500 | ~125 | 不再漏检轻声 |
| 正常环境 | ~200 | 500 | ~500 | 与旧版持平 |
| 嘈杂环境 | ~600 | 500 | ~1500 | 减少误触发 |

新增常量：`VAD_CALIBRATION_SEC=0.3`, `VAD_NOISE_MULTIPLIER=2.5`, `VAD_MIN_THRESHOLD=100`

### 2. AGC 自动增益控制

录音结束后分析语音段 RMS，自动归一化到目标水平：

```
gain = AGC_TARGET_RMS / current_rms    (限制在 0.3× ~ 5.0×)
RMS 已在目标范围 ±50% 内 → 跳过 AGC
```

新增常量：`ENABLE_AGC=True`, `AGC_TARGET_RMS=2000`, `AGC_MIN_GAIN=0.3`, `AGC_MAX_GAIN=5.0`, `AGC_TOLERANCE_RATIO=0.5`

### 3. DC 偏移去除

最简单的"高通滤波"——去除麦克风的直流偏置：

```python
samples -= mean(samples)
```

DC 偏移会干扰 VAD 能量计算的准确性。新增常量：`ENABLE_DC_REMOVAL=True`

### 4. 无语音超时

启动录音后若 3 秒内未检测到任何语音，提前中止并返回 "没有检测到语音，请重试"，不再等待 `MAX_RECORD_SECONDS`。

新增常量：`NO_VOICE_TIMEOUT=3.0`

### 5. 后处理纠错字典

常见 Vosk 误识别自动修正（长词优先匹配）：

| 误识别 | 纠正 | 场景 |
|--------|------|------|
| 教一下 | 叫一下 | "一分钟后叫一下" |
| 教醒我 | 叫醒我 | "明天8点叫醒我" |
| 教醒 | 叫醒 | 同上 |
| 教我 | 叫我 | "5分钟后叫我" |
| 教 | 叫 | 通用"叫"被识别为"教" |

`_apply_corrections()` 在 `listen_once()` 返回前调用，确保纠错后的文字送入路由层。

### 6. 增强调试日志

所有新增功能（AGC 增益/dB、VAD 校准噪声底噪、动态阈值）均在 `XIAOFENG_DEBUG=1` 时可观测。

## 处理管线（v3.7.7）

```
麦克风 → 音频流 → [动态VAD校准] → [静音检测/无语音超时] → 停止录音
  → DC偏移去除 → AGC增益归一化 → PCM字节流
  → Vosk识别 → 后处理纠错 → 返回文字
```

## 向后兼容

- 所有新功能通过常量开关控制（`ENABLE_AGC`, `ENABLE_DC_REMOVAL`），可单独关闭
- 默认 `SILENCE_THRESHOLD=500` 保留为初始值，校准后自动覆盖
- 未安装 numpy 或 sounddevice 时不受影响（已处理 ImportError）
- POST_CORRECTIONS 为纯文本替换，不影响识别流程
