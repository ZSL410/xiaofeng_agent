# v3.5.0 — 规律遗忘机制

**日期**：2026-06-22  
**类型**：新功能  
**版本**：v3.3.0 → v3.5.0

## 变更摘要

新增记忆衰减与用户反馈闭环：30 天未触发的规律自动衰减置信度，用户明确拒绝立即降权，低于阈值自动清除。

## 核心改动

### `记忆引擎.py` — 新增 3 个函数

| 函数 | 触发方式 | 效果 |
|------|----------|------|
| `decay_patterns()` | 启动时每周自动 | 30天未触发 → confidence -0.12/周；<0.3 删除 |
| `reject_pattern(content)` | 用户说"不用X" | 立即 confidence -0.30，标记 rejected=true |
| `boost_pattern(content)` | 用户确认时 | confidence +0.10，清除 rejected 标记 |

### `数据提炼.py`

- 新创建的 pattern 自动注入 `last_triggered` 和 `rejected` 字段
- 与旧模式合并时保留已有的 `rejected` 状态

### `脑.py`

- `_try_weekly_decay()`：启动时检查 `last_decay`，≥7 天自动执行
- 用户拒绝意图处理：正则匹配 `不用X` / `不要X`，调用 `reject_pattern()`

## 记忆生命周期

```
发现规律(refine) → 置信度 0.5-0.95
  ├─ 用户确认(boost)  → confidence +0.10
  ├─ 30天未触发(decay) → confidence -0.12/周
  ├─ 用户拒绝(reject)  → confidence -0.30
  └─ confidence < 0.3   → 删除
```
