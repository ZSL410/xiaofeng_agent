# v3.12.0 — 情绪检测与记忆关联（Phase 6）

> **日期**：2026-08-16 ｜ **类型**：⚡ 新功能 —— 记忆系统 Phase 6（情绪检测 + 知识图谱关联）

## 背景

前五阶段让晓风能**存**（归档）、**省**（渐进披露）、**找**（标签/时间索引）、**养**（置信度衰减）、**读**（对比分析），
但还差两块"人味"：**不知道用户此刻什么心情**，也**看不懂记忆之间的内在联系**。Phase 6 为晓风补上：
1. **情绪检测** —— 从对话/事件描述自动识别 9 类情绪，写入 `mood` 字段
2. **记忆关联** —— 为相关记忆建立 `related_ids` 关联网络（知识图谱雏形）

## 新增功能

### Feature 1: 情绪检测（hybrid：关键词优先 + LLM 兜底）

9 类情绪：开心 / 难过 / 生气 / 焦虑 / 平静 / 兴奋 / 疲惫 / 专注 / 困惑。

| 层 | 触发条件 | 行为 |
|----|----------|------|
| 关键词 | 命中情绪关键词表（如 开心/焦虑/累/不懂…） | 直接返回该情绪（零 LLM，覆盖 ~80%） |
| LLM 兜底 | 无关键词 + 文本含情绪信号词（被/失败/终于/吓…）+ 钩子已注入 | 3b 分类（2s 超时），9 类之一 |
| 无结果 | 均未命中 | 返回 `None`（不写入 mood） |

性能保障：关键词检测 O(9×关键词数) 纯字符串匹配，不拖慢主循环；LLM 仅在有信号词且关键词未命中时触发，
且**刻意排除「今天/最近」等高频中性词**，避免对每条记录都调 LLM。

### Feature 2: 记忆关联（知识图谱）

| 关联维度 | 判定 |
|----------|------|
| 同实体 | 实体主题标签重叠 ≥1（咖啡/会议/吃饭/运动…） |
| 同标签 | 标签重叠 ≥2 |
| 时间临近 | datetime 相差 ≤1 小时 |

| 强度 | 值 | 判定 |
|------|----|------|
| 强 (strong) | 1.0 | 同实体 + 同标签 + 时间临近 |
| 中 (medium) | 0.7 | 同实体（部分条件） |
| 弱 (weak) | 0.4 | 仅同标签 ≥2 或仅时间临近 |

`related_ids` 存储格式（additive，不覆盖已有）：

```json
[{"id": "memory_20260816_0105_xla50t", "strength": 1.0, "reasons": ["同实体:咖啡", "同标签", "时间临近"], "linked_at": "2026-08-16T01:05:00"}]
```

## 变更内容

### `记忆引擎.py` — 新增 Phase 6 函数（约 290 行）

情绪检测：
- `detect_mood(text, llm_fn=None)` — 关键词优先 + LLM 兜底，返回 9 类之一或 `None`
- `set_mood_llm_fn(fn)` — 模块级 LLM 钩子（脑.py 启动注入 `_call_ollama_3b`；未设置则纯关键词，引擎可独立运行）

记忆关联：
- `find_related_memories(new_memory, limit=5)` — 按 同实体/同标签/时间临近 匹配，返回 `[{id, strength, reasons, linked_at}]`
- `link_memories(memory_id, related)` — additive 双向写入 `related_ids`（同对 strength 取 max、reasons 合并去重）
- `build_association_network(limit_per=5)` — 批量重建全库关联网络（幂等、additive）
- `get_related_memories(memory_id, limit=None)` — 查询某记忆的关联记忆（按强度降序）

集成点：
- `add_memory_event()` — `mood is None` 时自动 `detect_mood(内容+标题)`；创建后自动 `find_related_memories` → `link_memories`
- `add_dialogue_record()` — `role=user` 且未显式传入 mood 时自动检测（assistant 轮不检测，避免噪音）
- `_maybe_run_daily_maintenance()` — 每日维护追加 `build_association_network()` 补全历史关联

### `脑.py` — 集成与版本

- 顶部 import `set_mood_llm_fn` / `get_related_memories`
- `_call_ollama_3b` 定义后注入 `set_mood_llm_fn(_call_ollama_3b)`（v3.12.0 注释标记）
- 新增确定性预路由 **(J) 关联记忆查询**：`"咖啡和什么相关"/"查看关联记忆"` → 提取主题 → `search_by_keyword` 定位 → `get_related_memories` 展示关联（排除 添加/记住/删除/提醒/记账 等强意图，防劫持）
- VERSION 常量 `3.11.1 → 3.12.0`
