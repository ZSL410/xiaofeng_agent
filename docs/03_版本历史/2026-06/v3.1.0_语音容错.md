# v3.1.0 — LLM 路由语义增强 + 语音容错

**日期**：2026-06-20  
**类型**：新功能  
**版本**：v3.0.0 → v3.1.0

## 变更摘要

路由层从简单意图分类升级为结构化参数提取引擎，具备语音识别偏差的容错理解能力。

## 核心改动

### `脑.py`
- `_ROUTE_PROMPT_V2`：全新提示词，含语音识别容错规则
  - `教`→`叫` 误识别容错
  - 纯数字+信号词识别（`38叫我` → 当前小时:38）
  - 注入当前时间上下文
- 结构化参数提取：`time_offset`、`absolute_time`、`content`、`raw_text`
- `num_predict`：20 → 200；超时：3s → 5s

### `schedule_module.py`
- 新增 `add_reminder_from_params(params)`：接收结构化参数直接创建待办
- 三级时间降级：路由参数 → 正则 → LLM → 1分钟兜底

### `手.py`
- `call_tool()` 支持 `_func` 参数，可调用模块内任意命名函数
