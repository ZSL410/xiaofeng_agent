# v3.10.7 — 记忆系统 Phase 3：标签生成 + 时间索引

> **日期**：2026-08-13 ｜ **类型**：⚡ 记忆系统 Phase 3（标签自动生成 + 时间范围查询）

## 背景

Phase 2 已完成渐进披露（只注入摘要 + 按需展开）。此时 `tags` 字段虽已存在但大量为空，
搜索只覆盖记忆库（不含对话归档），时间查询只支持 今天/昨天/本周/上周/本月 五种相对词，
无法按星期（"上周三"）或自定义日期范围查询。

## 变更内容

### 1. 标签自动生成（`记忆引擎.py`）

- 新增 `_extract_tags(text, extra_text, limit)`：**实体标签优先**（咖啡/会议/吃饭/运动/饮品/娱乐/阅读/情绪/购物/喝水 规则表），其次**类型标签**（财务/日程/记忆），无命中兜底「聊天」。去重、上限 5。
- 新增 `_merge_tags(provided, auto)`：传入标签与自动标签合并（去重、保序）。
- 写入钩子：
  - `add_dialogue_record`：原文+摘要 自动生成，与传入标签合并（脑.py 的 user 基础标签 / assistant 空标签统一被补齐）
  - `add_memory_event`：内容+标题 自动生成，与传入标签合并（财务/日程模块已有标签得到实体增强，如 `["财务"]`→`["财务","吃饭"]`）
  - `_fact_to_memory`：无显式标签时按 类别+内容 生成
- 新增 `backfill_tags()`：为**历史**空标签记录补齐（幂等，只补空不改已有），模块导入时随 `_migrate_if_needed()` 自动执行。当前 160 条对话 + 44 条记忆已 100% 补齐标签。
- 脑.py 的 `_generate_dialogue_tags` 统一委托 `_extract_tags`（原 `_DIALOGUE_TAG_RULES` 规则表移除）。

### 2. 时间索引（`记忆引擎.py`）

- 新增 `_resolve_date_range(date_range)`：统一解析时间词 → `(start, end)` 日期范围。
  - 相对词：今天/昨天/本周/上周/本月（复用 `_date_range_for`）
  - **星期**：周一~周日（本周对应日）、**上周X**（上周对应日，如 `上周三` → 上周三日期）
  - 自定义：`YYYY-MM-DD` 单日，或 `(start, end)` 元组
- 新增 `search_by_time(date_range, period=None, limit)`：按日期范围 + 时段（凌晨/早上/…/深夜）筛选记忆，范围无法解析时返回空（不误返回全量）。

### 3. 搜索接口（`记忆引擎.py`）

| 函数 | 说明 |
|------|------|
| `search_by_tags(tags, limit)` | 按标签搜记忆库（单标签或列表，子串匹配，"咖啡"可命中"咖啡豆"） |
| `search_by_time(date_range, period)` | 按时间范围/时段搜记忆 |
| `search_by_keyword(keyword, limit)` | 搜**记忆 + 对话归档**（content/title/detail/original_text/summary/tags），统一结构返回，日期降序 + 记忆优先 |

### 4. 路由集成（`脑.py`）

- **预路由 (C) 搜索**升级：`search_dialogue`→`search_by_keyword`（记忆 + 对话归档）。排除词移除"会议"（"搜索会议"命中验收 #5）。
- **预路由 (D) 记忆查询**升级：`get_memories(time_filter)`→`search_by_time(_extract_memory_time_expr)`。
- **新增预路由 (I) 时间回查**："上周三发生了什么"/"周一干了什么"/"昨天都做了啥" → `search_by_time`。排除"有什么安排"等模糊表达（避免误吞日程查询）。
- **3b 路由**：`search` 意图 → `search_by_keyword`；`query+memory` 意图 → `search_by_time`（含时间兜底提取）。
- 新增 `_extract_memory_time_expr(text)`：提取时间词（"上周三"优先于"上周"）。
- 版本号提升 `VERSION = "3.10.7"`。
