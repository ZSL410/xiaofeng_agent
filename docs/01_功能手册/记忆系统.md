# 记忆系统

## 概述

晓风的记忆系统分三层：短期记忆、长期记忆、行为模式提炼。

## 短期记忆

- **文件**：`00_核心主体/记忆/短期记忆.json`
- **容量**：最近 20 轮对话（user + assistant 交替）
- **生命周期**：程序退出时持久化，下次启动恢复
- **用途**：作为 LLM 对话的上下文窗口（最近 10 轮）

## 长期记忆

- **文件**：`00_核心主体/记忆/长期记忆.json`
- **结构**：
  ```json
  {
    "patterns": [...],
    "last_refined": "2026-06-22T12:00:00",
    "last_decay": "2026-06-22"
  }
  ```
- **用途**：跨会话的用户信息、行为模式

## 数据提炼（v3.3.0）

`数据提炼.py` — 扫描历史待办/日程，自动发现三种行为模式：

| 类型 | 发现什么 | 最低样本 |
|------|----------|----------|
| `time_based` | 同一内容在相似时段重复 | ≥2 |
| `interval` | 同一内容以固定间隔创建 | ≥3 |
| `association` | A 创建后频繁跟随 B | ≥2 |

启动时每日自动提炼一次（`_try_daily_refine()`）。

## 遗忘机制（v3.5.0）

`记忆引擎.py` 中的三个函数：

| 函数 | 效果 |
|------|------|
| `decay_patterns()` | 30 天未触发 → 每周 confidence -0.12 |
| `reject_pattern()` | 用户拒绝 → 立即 confidence -0.30 |
| `boost_pattern()` | 用户确认 → confidence +0.10 |

confidence < 0.3 的模式自动删除。
