# v3.1.4 — 残留输入过滤增强

**日期**：2026-06-22  
**类型**：Bug 修复  
**版本**：v3.1.3 → v3.1.4

## 变更摘要

修复 IDE 终端残留命令被 `input()` 自动读取导致误回复的问题。过滤规则从前缀匹配升级为 12 条正则模式匹配。

## 核心改动

### `脑.py`

- **过滤规则升级**：前缀匹配 `("set-executionpolicy", "&", "powershell", "d:/")` → 12 条正则模式
  - 盘符路径：`^[a-zA-Z]:[\\/]`
  - venv 路径：`[\\/]\.venv[\\/]`、`[\\/]Scripts[\\/]`
  - 关键词：`activate`、`Set-ExecutionPolicy`、`PowerShell`
  - 命令连接符：`&\s*(?:chcp|powershell|cmd|\.)`
- **启动缓冲区清理**：增加 `sys.platform` 守卫，仅在 win32 执行 `msvcrt` 清理
- **提示文案**：改为 `[系统] 检测到残留输入，已自动忽略`
