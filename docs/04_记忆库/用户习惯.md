# 用户习惯

> 此文件由 `数据提炼.py` 自动生成和维护。手动编辑可能被下次提炼覆盖。

## 当前提炼状态

_尚未执行数据提炼，或长期记忆中没有已发现的模式。_

启动晓风后，每天会自动执行一次数据提炼。也可以输入 `提炼规律` 手动触发。

## 可能的习惯类型

- **时段习惯**：每天固定时间重复的行为（如 8:00-9:00 泡咖啡）
- **固定间隔**：以固定周期重复的行为（如每 30 分钟喝水）
- **内容关联**：行为之间的链式关系（如冥想 → 休息）

## 置信度说明

| 置信度 | 含义 |
|--------|------|
| 0.80-0.95 | 高度确定，多次重复验证 |
| 0.50-0.75 | 中等确定，有一定重复 |
| 0.30-0.45 | 低置信度，接近遗忘阈值 |
| <0.30 | 自动删除 |
