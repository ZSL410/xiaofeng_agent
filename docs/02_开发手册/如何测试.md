# 如何测试

## 模块独立测试

### 日程模块
```bash
python 01_工具模块/日程模块/schedule_module.py
```
进入交互测试模式，直接输入日程指令。

### 数据提炼模块
```bash
python 00_核心主体/记忆/数据提炼.py
```
独立运行模式提炼并打印结果。

### 财务报告
```bash
python -c "import sys; sys.path.insert(0, '01_工具模块/财务模块'); import finance_module; finance_module.generate_report()"
```
（旧版独立脚本已归档到 `docs/99_归档/generate_report.py`）

## 编译验证

```bash
python -m py_compile 00_核心主体/脑.py
python -m py_compile 01_工具模块/日程模块/schedule_module.py
python -m py_compile 00_核心主体/记忆/记忆引擎.py
```

## 调试日志

设置环境变量启用详细日志：
```bash
DEBUG=1 python 00_核心主体/脑.py
```

## 常见测试场景

| 场景 | 输入 | 预期结果 |
|------|------|----------|
| 创建提醒 | `5分钟后叫我喝水` | 创建待办，到期时间 now+5min |
| 模糊删除 | `把两个小时的定时删掉` | 按描述匹配删除 |
| 修正提醒 | `不是5分钟是10分钟` | 删除旧，创建新（now+10min） |
| 语音容错 | `5分钟教我泡咖啡` | 创建提醒，内容"泡咖啡" |
| 残留过滤 | `d:\path\to\.venv\Scripts\activate` | 输出 `[系统] 检测到残留输入，已自动忽略` |
