# v3.7.6 — 动态澄清消息：上下文感知的删除问询

**日期**：2026-07-15  
**类型**：增强 (enhancement)  
**影响范围**：`00_核心主体/脑.py` — `_ROUTE_PROMPT_V2` + `_parse_delete_scope()` + 澄清状态机 + 降级匹配

## 问题描述

v3.7.4/v3.7.5 的澄清流程使用硬编码模板——不管用户说什么，系统都回复同一个问句。缺乏对上下文的感知：

- 用户说"删除财务数据" → 系统应问"删除全部财务记录？还是最近一周的？"
- 用户说"删除记忆" → 系统应问"删除全部记忆数据？还是最近一周的？"
- 用户说"删除数据" → 系统应先问"哪种数据？"再问"什么范围？"

## 变更内容

### 1. 动态 target_type 推断

路由提示词新增 4 级 `target_type` 推断规则：

| 用户输入特征 | target_type |
|-------------|-------------|
| 含"财务"/"记账"/"账单"/"消费"/"收入"/"支出" | `finance` |
| 含"日程"/"提醒"/"待办"/"任务"/"事件" | `schedule` |
| 含"记忆"/"记住"/"记忆数据" | `memory` |
| 仅有"数据"/"之前"/"全部"，无任何模块词 | `unknown` |

### 2. 上下文感知的 message 生成

| target_type | 澄清问句模板 |
|-------------|-------------|
| `finance` | "你想删除全部财务记录，还是最近一周的？还是最新一条？" |
| `schedule` | "你想删除全部日程/待办，还是最近一周的？还是最新一条？" |
| `memory` | "你想删除全部记忆数据，还是最近一周的？还是最新一条？" |
| `unknown` | "你想删除哪种数据？是财务记录、日程待办、还是记忆数据？" |

LLM 根据用户原文中的动词（"删除" / "清空"）动态调整问句措辞。

### 3. 两步澄清流程

当 `target_type="unknown"` 时，系统分两步完成澄清：

```
步骤 1: 确认数据类型
  用户: "删除数据"
  系统: "你想删除哪种数据？是财务记录、日程待办、还是记忆数据？"
  
步骤 2: 确认删除范围（仅当用户回复纯类型词时触发）
  用户: "财务"
  系统: "你想删除全部财务记录，还是最近一周的？还是最新一条？"
  
步骤 3: 执行
  用户: "全部"
  系统: ✅ 已清空全部 N 条财务记录
```

如果用户在第二步同时指定了类型和范围（如"财务的全部"），则一步直达执行。

实现方式：澄清状态机检测 `original_target == "unknown" and scope == "keyword" and type_override` 时，不执行删除而是重新发起 `_pending_clarification`，用解析出的 target_type 生成范围问句。

### 4. 新增记忆类型支持

| 维度 | 内容 |
|------|------|
| 路由提示词 | 新增 `memory` target_type 推断规则和 JSON 示例 |
| `_parse_delete_scope()` | 新增 `["记忆", "记住", "记忆数据"]` → `"memory"` |
| 澄清状态机 | 新增 `target_type == "memory"` 分支，提示用户使用「清理记忆」命令 |
| 降级匹配 | 新增 `MEMORY_CTX_KW` 检查 |

记忆删除的执行暂不直接操作文件（记忆系统有自己的衰减/归档机制），而是引导用户使用现有命令。

### 5. 降级匹配增强

| 旧版 | 新版 |
|------|------|
| 仅检测 finance 上下文 | 检测 finance / schedule / memory / unknown 四类 |
| 非 finance 全部走 delete_reminder | 按类型生成对应的 ask_clarify 消息 |

## 路由输出示例

LLM 现在根据输入动态生成不同的 JSON：

```json
// "删除财务数据"
{"tool":"ask_clarify","action":"delete_scope",
 "params":{"target_type":"finance",
 "message":"你想删除全部财务记录，还是最近一周的？还是最新一条？"},
 "confidence":0.95}

// "删除记忆"
{"tool":"ask_clarify","action":"delete_scope",
 "params":{"target_type":"memory",
 "message":"你想删除全部记忆数据，还是最近一周的？还是最新一条？"},
 "confidence":0.95}

// "清空所有"
{"tool":"ask_clarify","action":"delete_scope",
 "params":{"target_type":"unknown",
 "message":"你想清空哪种数据？是财务记录、日程待办、还是记忆数据？"},
 "confidence":0.95}
```
