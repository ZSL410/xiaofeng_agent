# v3.10.3 — 展开预路由触发增强

> **日期**：2026-08-12 ｜ **类型**：🐛 预路由修复（Hook H 触发增强 + 回退逻辑）

## 背景

Phase 2 的展开预路由 (H) 触发模式偏窄，部分结构不同的展开请求未按预期路由。实测"详细说一下我跟他干了什么事"曾被 3b 误判为财务查询。

## 根因

(H) 的触发词只覆盖固定短语（详细说说/展开讲讲 等），对"详细说一下 + 主语 + 干了什么"这类结构化表达识别不稳；且当对话归档中找不到记录时，(H) 会返回固定文案"暂时没有找到"，**吞掉该轮**而不回退正常路由。

## 变更内容（`脑.py` 主循环 Hook H）

### 1. 结构化触发模式（v3.10.3）

`_EXPAND_RE` 扩充为多模式组合：

| 模式 | 示例 |
|------|------|
| `详细说[一下]? + … + 干了/说了/讲了/做了什么` | 详细说一下我跟他干了什么事 |
| `详细讲讲 + … + 干了/说了什么` | 详细讲讲我们聊了什么 |
| `展开说[一下]? / 展开讲讲 / 展开` | 展开说一下刚才的内容 |
| `具体说说 + … + 那件事/这件事/刚才/之前/聊了什么` | 具体说说我们聊了什么 |
| `把那件事/那句话/那段话 + 详细说说/展开` | 把那句话展开一下 |
| `详细说说 + 他/她/我们/你们` | 详细说说他讲了什么 |

排除词不变（财务/日程/查询/删除/提醒），"详细说一下我的财务记录"仍正确落财务、"详细介绍你自己"走 chat。

### 2. 回退逻辑（不吞轮）

**关键修复**：当 (H) 触发但对话归档找不到匹配记录时，**回退到正常路由**（finance/schedule/chat），不再返回固定"没有记录"文案吞掉该轮。

### 3. DEBUG 日志

- 触发时打印展开目标记录 `record_id`
- 未命中 / 排除词拦截 / 回退 均有 `[DEBUG-预路由] (H)` 日志
