## 数据流

```
用户输入 → add_dialogue_record(mood=detect_mood(text)) → 对话归档.json
         → add_memory_event(mood=detect_mood(title), related=find_related_memories)
             → link_memories(双向 additive) → memory.json
每日维护 → build_association_network() 补全历史关联
```

## 已确认的关键决策

1. **LLM 钩子**：模块级 `set_mood_llm_fn`（脑.py 启动注入），引擎独立运行不依赖 LLM
2. **related_ids 格式**：存 `[{"id", "strength", "reasons", "linked_at"}]` 列表（含强度与原因）

## 验收标准

| # | 输入 | 期望 |
|---|------|------|
| 1 | 我今天心情很好 | memory/对话 mood=开心 |
| 2 | 最近压力很大，有点焦虑 | mood=焦虑 |
| 3 | 两次提到"咖啡" | 两记忆 related_ids 互相关联 |
| 4 | 1 小时内连续两条记录 | 时间临近关联 |
| 5 | 查看关联记忆 | get_related_memories 返回关联记忆 |
