# 财务模块

## 概述

`01_工具模块/财务模块/` — 自然语言记账、查账、财务报告生成。

## 核心功能

### 1. 自然语言记账

```
"记账午餐30元"          → 解析金额/类型/来源 → 存入 local_archive.json
"帮我记一下打车25块"     → 同上
"花了50买书"            → 同上
```

解析引擎：从口语中提取金额、消费类型、来源。

### 2. 查账

```
"查账这个月"            → 汇总本月消费
"花了多少钱"             → 查询总支出
```

### 3. 财务报告生成

```bash
python 01_工具模块/财务模块/generate_report.py
```

- 读取 `local_archive.json`
- 调用 Ollama 生成消费总结
- 输出 Word 文档到项目根目录 `每日财务/`

## 数据文件

| 文件 | 用途 |
|------|------|
| `local_archive.json` | 记账记录（金额、类型、来源、时间） |
| `memory.json` | 用户财务画像（偏好、常用来源） |
