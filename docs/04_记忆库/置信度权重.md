# 置信度权重

> 记录系统中各预测/解析的准确率，用于调整模型行为。

## 路由层

| 组件 | 当前配置 | 说明 |
|------|----------|------|
| 主模型超时 | 8s | qwen2.5:7b |
| 降级模型超时 | 5s | qwen2.5:3b |
| 低置信度阈值 | 0.6 | 低于此值触发确认 |
| 修正意图最低置信度 | 0.85 | 纠错表达天然高置信度 |

## 数据提炼

| 组件 | 当前配置 | 说明 |
|------|----------|------|
| 时间聚类窗口 | 60 分钟 | time_based 模式的时间窗口 |
| 间隔容差 | ±25% | interval 模式的允许偏差 |
| 遗忘阈值 | 0.3 | 低于此值删除模式 |
| 衰减速率 | 0.12/周 | 30天未触发后每周衰减量 |
| 拒绝惩罚 | -0.30 | 用户拒绝时立即降低 |
| 确认奖励 | +0.10 | 用户确认时提升 |

## 提醒解析

| 组件 | 说明 |
|------|------|
| 正则解析 | 首选（快速、精确） |
| LLM 解析 | 降级（覆盖自然口语） |
| 1 分钟兜底 | 最终保底（确保提醒不丢失） |
