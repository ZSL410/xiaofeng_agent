# 对话系统

## 概述

晓风的对话系统以 `脑.py` 为核心，采用 LLM 驱动的意图路由架构。用户输入（文字或语音）经规范化处理后，由路由层判定意图并分发到对应工具模块。

## 核心流程

1. **文本规范化**：`input()` 读取 → 折叠多余空格 → 移除中文字符间空格
2. **残留过滤**：13 条正则模式拦截终端残留命令
3. **删除否定检查**：用户说"不要删除数据"等时直接阻断删除路径（v3.9.1）
4. **确认状态机**：低置信度提醒先确认再执行
5. **LLM 路由**：qwen2.5:3b（主路由，3s，confidence ≥ 0.6 直接执行）→ qwen2.5:7b（8s 兜底）→ 关键词匹配兜底
6. **工具分发**：`手.py` 动态 import 目标模块（`call_tool` 支持 `_func` 命名函数模式）
7. **回复层**：`_generate_tool_reply` 将工具结构化结果转为温暖自然回复，自动追加追问（v3.9.23）
8. **语音输出**：文字 + Edge TTS 语音双通道输出

## 路由意图类型

3b 主路由（`_ROUTE_PROMPT_3B`）返回 `{intent, target, params, confidence}`，意图类型：

| 意图 | target | 说明 |
|------|--------|------|
| `record` | finance | 记账 |
| `query` | finance / schedule | 查账 / 查日程 |
| `delete` | finance / schedule / memory | 删除记录 / 提醒 / 记忆 |
| `remind` | schedule | 创建定时提醒待办 |
| `correct` | schedule | 纠正上次提醒参数（"不是X是Y"） |
| `recall` | null | 回顾短期记忆（对话总结） |
| `chat` | null | 通用对话（v3.9.21 起优先级最高） |
| `clarify` | null | 输入模糊，需澄清 |

> **chat 优先级规则（v3.9.21）**：当输入可能同时匹配"工具关键词"和"聊天关键词"时，优先判定为聊天。理由：聊天误判为工具的代价（功能查询被当成 clarify 冷冰冰回复）比工具误判为聊天的代价更大。
> 聊天触发词：你好、你是谁、你会什么、你能干什么、讲讲笑话、今天天气不错、聊聊、随便聊…（约 60 个，见脑.py `_ROUTE_PROMPT_3B`）。

## 语音交互

- 输入 `v` → VAD 动态录音（静音 1.5s 自动停止，最长 25s）→ Vosk 离线识别 → 转为文字
- 语音识别容错：`教`→`叫`、中文字符间空格修复
- 输出：Edge TTS 合成语音 + 终端文字

## 确认机制

- **3b 主路由**：confidence ≥ 0.6 直接执行，不确认（保证速度）
- **降级路由**（7b→3b）：当置信度 < 0.6 时：
  - `add_reminder` 意图 → 打印 `🤔 你是想说「…」吗？`，等待用户确认（是/不是）
  - 财务/日程删除等 → 输出澄清提示（"请再说清楚一点"）
- 修正模式：`不是X是Y` → 自动删除旧提醒重建
