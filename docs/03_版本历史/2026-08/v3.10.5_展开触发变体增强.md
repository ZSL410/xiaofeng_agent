# v3.10.5 — 展开触发变体增强

> **日期**：2026-08-12 ｜ **类型**：🐛 展开预路由触发补充（Hook H）

## 背景

实测发现 `详细跟我说一说`、`详细跟我讲一下...` 等无"地"的口语变体仍未触发展开，被 3b 误判为 clarify。

## 变更内容（`脑.py` Hook H `_EXPAND_RE`）

新增 4 类模式，覆盖口语常见变体：

| 新增模式 | 匹配示例 |
|----------|----------|
| `详细跟(我\|我们) + 说/讲/说说/讲讲/一说/说一下/讲一下` | 详细跟我说一说 / 详细跟我讲一下 |
| `详细给(我\|我们) + 说/讲/...` | 详细给我讲一下 |
| `跟(我\|我们)详细 + 说/讲/...` | 跟我详细说说 |
| `详细(说说\|讲讲) + 刚才/之前/那件事/这件事` | 详细说说刚才的事 |

同时 `详细地`（有"地"）与 `跟…详细`（倒装）变体已在 v3.10.4 覆盖，本次补全无"地"的顺装形式。`说`/`讲` 视为可互换触发词。

**DEBUG 日志**：触发时输出 `匹配模式: <命中的子串>`（如 `匹配模式: '详细跟我讲'`）。

## 自检结果

| # | 用例 | 结果 |
|---|------|------|
| 1 | 详细跟我说一说 → expand_dialogue（非 clarify） | ✅ |
| 2 | 详细跟我讲一下你刚才怎么夸的我 → expand_dialogue | ✅ |
| 3 | 跟我详细说说刚才的事 → expand_dialogue | ✅ |
| 4 | 详细给我讲一下 → expand_dialogue | ✅ |
| 负向 | 详细说一下我的财务记录 / 详细说说今天的日程 / 详细介绍你自己 → 不触发 | ✅ |

> 自检 **4/4 + 负向 3 例 + 主循环端到端** 通过。主循环 4 用例全部进入展开、无 clarify，DEBUG 日志显示命中子串。
