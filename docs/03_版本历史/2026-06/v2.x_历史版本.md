# v2.x 历史版本汇总

> 以下版本为 LLM 路由重构之前的迭代，统一归档于此。

## v2.7.2 (2026-06-20) — LLM时间解析引擎

- 新增 `_parse_time_with_llm()` 函数
- 三级降级链：正则 → LLM → 1分钟后兜底
- 扩展提醒关键词和 `_has_time_pattern()` 模式

## v2.7.1 (2026-06-19) — 残留命令过滤

- 新增前缀过滤拦截 PowerShell 残留命令
- 按键缓冲区清理（Windows msvcrt）

## v2.7.0 (2026-06-19) — 智能提醒文案

- `_generate_smart_reminder()`：Ollama 驱动的人性化播报
- `模型.json` 新增 `use_smart_reminder` 开关

## v2.6.2 (2026-06-18) — 文本规范化 + 日志静默

- 语音空格容错（中文字符间空格移除）
- `_debug_log()` 门控，环境变量 `DEBUG=true` 启用

## v2.6.1 (2026-06-18) — 日程提醒模块修复

- 扩展日程路由关键词（叫我/叫醒/喊我/通知/闹钟/分钟后）
- 提醒线程显式启动
- `_normalize_chinese_numbers()` 中文数字转换

## v2.6.0 (2026-06-18) — 语音识别兼容性修复

- 录音数据格式强化校验
- Vosk 识别管线升级（流式分块 + FinalResult 冲刷）
- Windows 麦克风诊断

## v2.5.x — 基础架构

- 多后端录音架构（parec / sounddevice / mock）
- Vosk 离线中文语音识别
- WSL2 / Linux / Windows 跨平台支持
- Edge TTS 语音合成
- 财务记账 NLU 引擎
- 短期记忆 + 长期记忆框架
- 日程提醒守护线程
