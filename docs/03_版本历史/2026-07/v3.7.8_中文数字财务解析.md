# v3.7.8 — 财务模块支持中文数字解析

**日期**：2026-07-19  
**类型**：增强 (enhancement)  
**影响范围**：`01_工具模块/财务模块/finance_module.py`

## 变更动机

财务模块的 `parse_user_input()` 和 `parse_natural_language_for_expense()` 仅识别阿拉伯数字（如"6元"），无法处理中文数字表达（如"六元"、"十五块钱"），导致用户使用中文数字时报"没听懂金额"。

## 变更内容

### 1. 新增 `_chinese_to_number()` 转换函数

将文本中的中文数字序列转换为阿拉伯数字，支持：

| 类型 | 中文 | 转换结果 | 说明 |
|------|------|----------|------|
| 个位 | 六 | 6 | 基本数字映射 |
| 十位 | 十五 | 15 | 十 + 五 |
| 十位 | 二十 | 20 | 二 × 十 |
| 百位 | 一百二十三 | 123 | 一×百 + 二×十 + 三 |
| 千位省略 | 三千五 | 3500 | 三千 + 五百（省略"百"） |
| 万位省略 | 一万二 | 12000 | 一万 + 二千（省略"千"） |
| 小数 | 三点五 | 3.5 | 点 = 小数点 |
| 角（毛） | 十二块五 | 12.5 | 块后单数字 → 角 |
| 半 | 一块半 | 1.5 | 块半 → +0.5 |
| 两 | 两块 | 2块 | 两 = 2 |

**实现**：扫描文本中的中文数字字符连续序列，逐段转换为阿拉伯数字后替换回原文。转换分三步：
1. 中文数字序列 → 阿拉伯数字（含小数点处理）
2. `块X` 模式 → `.X元`（角→小数）
3. `块半` 模式 → 补 0.5

### 2. `parse_user_input()` 集成

在金额提取之前调用 `_chinese_to_number()`，正则从 `r'\d+'` 升级为 `r'\d+\.?\d*'` 以支持小数金额。

### 3. `parse_natural_language_for_expense()` 集成

同样调用 `_chinese_to_number()` 后提取金额。**增强**：优先匹配紧邻货币单位（元/块/角/毛）的数字，避免将数量词（如"两个"）误解析为金额。

### 4. 向后兼容

- 阿拉伯数字输入完全不受影响
- 所有原有金额格式（"花了X元"、"X块钱"、"消费X"等）保持支持
- 金额类型：整数保持 `int`，小数使用 `float`
