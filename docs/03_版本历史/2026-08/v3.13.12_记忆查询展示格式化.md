# v3.13.12 — 记忆查询展示格式化（Phase 7, Fix C）

> **日期**：2026-08-22 ｜ **类型**：⚡ 改进 —— 「查看今天的记忆」按类型分组展示

## 背景

Phase 7 测试发现：「查看今天的记忆」返回杂乱列表（`[date] (subtype) title`），
无分组、无可读性。

## 修复内容

### `记忆/记忆引擎.py`

1. **`format_memory_query(records, header="记忆记录", time_label=None)`**：
   - 按 subtype 分组：事实/事件/情绪/习惯/其他
   - 事件组内财务记录合并为「记账 N 笔，共 X 元」（`_sum_amounts`），其余逐条展示
   - 每组展示条数、超出显示「…等 N 条」
   - 无记录 →「{time_label}没有{header}哦」
2. **`_display_text` 情绪展示增强**：情绪记忆显示为「开心（今天心情很好）」（mood + content）。
3. **对话噪音过滤补充**：`search_by_keyword` 跳过时间回查/记忆查询摘要回声
   （含"做了这些事"/"的记忆记录"/"找到 "），避免 Fix B/C 输出归档污染搜索结果。

### `脑.py`

- 预路由 (D)（查看/回忆记忆）改用 `format_memory_query`；limit 10→200 保证分组计数准确；
  检索提升限前 10 条。
- 3b 记忆查询镜像从 `format_time_recall` 改为 `format_memory_query`（记忆列表查询更适合分组展示）。
