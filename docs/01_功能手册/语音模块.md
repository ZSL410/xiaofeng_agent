# 语音模块

## 概述

晓风支持离线语音输入（Vosk）和在线语音合成（Edge TTS），实现完整的语音对话闭环。

## 语音输入（耳朵.py）

- **识别引擎**：Vosk 离线中文语音识别
- **模型**：`vosk-model-cn-0.22` (~170MB)
- **录音后端自动检测**：`parec`（PulseAudio/WSLg）→ `sounddevice`（PortAudio）→ `mock`（模拟，模型缺失时回退）
- **格式**：int16 PCM，16000Hz 单声道
- **容错**：模型未就位时自动回退到模拟文本

### VAD 动态录音（v3.7.2）

不再是固定 5 秒录音，而是基于 RMS 能量的动态录音：

| 参数 | 值 | 说明 |
|------|-----|------|
| 静音阈值 | RMS 500 | 低于此值视为静音 |
| 静音持续时间 | 1.5s | 连续静音 1.5s 自动停止录音 |
| 最大录音时长 | 25s | 超时强制停止，避免挂死 |
| 无语音超时 | 3s | 前 3s 无语音则中止 |
| 动态阈值 | 噪声底噪 × 2.5，最低 100 | 根据环境噪声自动校准 |

### AGC 自动增益（v3.7.7）

| 参数 | 值 | 说明 |
|------|-----|------|
| 启用 | true | `ENABLE_AGC` |
| 目标 RMS | 2000 | 校准后调整增益使音量达到目标 |
| 校准时长 | 0.5s | 用前 0.5s 音频计算当前 RMS |
| 增益范围 | 0.3 – 5.0 | 超出范围不调整 |
| 容差比例 | 0.5 | RMS 在 target×(1±0.5) 内不调整 |

### DC 偏移去除（v3.7.7）

`ENABLE_DC_REMOVAL=true`，录音后去除直流偏移，改善识别精度。

### 触发方式

在对话中输入 `v` 启动语音识别。

### 后处理纠错（v3.7.7）

识别结果应用纠错规则：`教我`→`叫我`、`教醒我`→`叫醒我` 等（`POST_CORRECTIONS`）。

## 语音合成（嘴巴.py）

- **引擎**：Edge TTS（微软在线 TTS）
- **语言**：中文普通话（zh-CN-XiaoxiaoNeural）
- **播放**：WSL 下通过 `cmd.exe /c start` 调用 Windows 播放器；纯 Linux 依次尝试 `mpv` → `ffplay`
- **音频缓存**：输出到项目根目录 `temp_response.mp3`（每次覆盖）

### 使用方式

```python
from 器官.嘴巴 import speak
speak("你好，我是晓风")
```

## 语音识别容错

路由层内置语音识别容错规则：
- `教`→`叫`：`"5分钟教我"` → 理解为 `"5分钟叫我"`
- 中文字符间空格：`"一 分钟 后 叫 我"` → `"一分钟后叫我"`
- 纯数字+信号词：`"38叫我"` → 当前小时:38
