# 如何添加新工具

## 步骤

### 1. 创建工具模块

在 `01_工具模块/` 下创建子目录，实现 `process_command()` 函数：

```python
# 01_工具模块/天气模块/weather_module.py

def process_command(text):
    """解析自然语言指令并返回结果"""
    if "天气" in text:
        return "今天晴，25°C"
    return "请说明要查询天气的城市"
```

### 2. 注册到工具分发器

在 `00_核心主体/器官/手.py` 的 `TOOL_MODULES` 中注册：

```python
TOOL_MODULES = {
    "财务": "财务模块.finance_module",
    "日程": "日程模块.schedule_module",
    "天气": "天气模块.weather_module",  # 新增
}
```

### 3. 注册到路由层

> ⚠️ `TOOLS` 列表已在 v3.8.7 死代码清理中移除。当前路由层使用硬编码提示词模板，无需注册表。

在 `脑.py` 的路由提示词模板中补充新工具的分类规则：

```python
# 脑.py 顶部
_ROUTE_PROMPT_V2 = """..."""   # 降级路由（7b→3b）提示词，含工具清单
_ROUTE_PROMPT_3B = """..."""   # 3b 主路由提示词，含意图/target 分类规则
```

- 在 `_ROUTE_PROMPT_3B` 的 target 推断优先级中补充新工具的关键词
- 在 `_ROUTE_PROMPT_V2` 的工具清单中加入新工具名
- 关键词匹配兜底逻辑（脑.py `main()` 中的 `SCHEDULE_KW` / `FINANCE_KW` 列表）可按需扩展

LLM 路由层据此将包含对应关键词的输入路由到新工具。

### 4. （可选）添加结构化参数入口

如果路由层需要直接传递结构化参数而非原始文本：

```python
# 在模块中实现
def get_weather(city):
    # ...

# 在 脑.py 中通过 _func 参数调用
call_tool("天气", city, _func="get_weather")
```
