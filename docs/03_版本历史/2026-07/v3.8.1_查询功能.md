# v3.8.1 — 财务查询功能

**日期**：2026-07-21  
**类型**：新增功能 (feature)  
**影响范围**：`01_工具模块/财务模块/finance_module.py`、`00_核心主体/脑.py`

## 变更动机

财务模块只支持记账和删除，用户无法查询已记录的财务数据。当用户说"看一下今天的记录"或"最近吃饭花了多少钱"时，路由到 `process_command` 会因为没有金额而报"没听懂金额"。

## 新增功能

### 1. `query_finance(query_text, params=None)` — 统一查询入口

支持两种查询模式：

**Mode B — 结构化查询**（`params` 参数传入）：

```python
query_finance("", params={"date_range": "today", "source": "饭"})
# → {"status": "success", "type": "query", "data": [...], "summary": "今天饭共2笔，合计30元"}
```

支持的过滤参数：

| 参数 | 可选值 | 说明 |
|------|--------|------|
| `date_range` | today / yesterday / this_week / last_week / this_month / last_month | 日期范围 |
| `source` | 饭 / 奶茶 / 咖啡 / 外卖 / 交通… | 来源过滤 |
| `aggregate` | sum / count / avg / max / min | 统计聚合 |
| `sort` | amount_desc / amount_asc / date_desc / date_asc | 排序 |
| `limit` | 整数 | 条数上限 |
| `amount_min` / `amount_max` | 数字 | 金额范围 |

**Mode C — 自然语言查询**（LLM 解析）：

```python
query_finance("最近吃饭花了多少钱")
# → LLM 解析 → {"date_range": "this_week", "source": "饭", "aggregate": "sum"}
# → 查询执行 → {"summary": "本周饭共3笔，合计45元"}
```

用户无需记忆参数格式，自然语言即可查询。

### 2. `_parse_query_nl(query_text)` — LLM 查询解析器

通过 Ollama（qwen2.5:7b）将自然语言查询转换为结构化参数：

| 用户输入 | LLM 解析结果 |
|----------|-------------|
| "最近吃饭花了多少钱" | `{date_range: "this_week", source: "饭", aggregate: "sum"}` |
| "这个月最大的开支" | `{date_range: "this_month", sort: "amount_desc", limit: 1}` |
| "上周交通费一共多少" | `{date_range: "last_week", source: "交通", aggregate: "sum"}` |
| "我最近花钱多吗" | `{date_range: "this_week", aggregate: "sum"}` |

**容错**：LLM 不可用时自动降级为 `date_range: "today"` 的全量查询。

### 3. `_execute_query(params)` — 查询引擎

六步管线：
```
加载全部数据 → 日期过滤 → 来源过滤 → 金额过滤 → 排序 → 聚合统计 → 生成摘要
```

自然语言摘要生成示例：
- "今天共2笔，合计23元"
- "本周饭共3笔，合计45元"
- "本月最大开支：外卖 120元"
- "2026-07-21 饭 15元（本周仅此一笔）"
- "昨天没有「交通」财务记录"

### 4. 路由层更新

**路由提示词** 新增 query action：
```
### 财务
- record(默认): 记账/报销/花了+金额 → action=null
- query: 查看/查/显示/统计/花了多少 → action="query"
```

**降级关键词** 新增 `QUERY_KW` 检测：
```python
QUERY_KW = ["查看", "查一下", "查", "显示", "统计", "花了多少",
            "一共", "列表", "最大", "有没有", "多少"]
is_query = any(kw in user_input for kw in QUERY_KW)
```

### 5. 主循环 query 路由

```python
if tool == "财务":
    if action == "query":
        result = call_tool("财务", user_input, query_params,
                           _func="query_finance")
    else:
        result = call_tool("财务", user_input)  # 原有记录流程
    reply = _generate_tool_reply(result)
```

### 6. 回复层 `_generate_tool_reply` 新增 query 类型

查询结果直接使用 summary 作为回复（无需额外前缀）：
```python
elif rtype == "query":
    return summary  # 摘要本身已完整
```

## 测试验证

```
Mode B:
  date_range=today              → "今天共2笔，合计23元"        ✅
  source=饭 + date_range=week   → "本周饭1笔..."              ✅
  aggregate=max                 → "最大开支: 饭 15元"         ✅
  aggregate=count               → "共6笔记录"                  ✅
  amount_min=50                 → 过滤仅显示 ≥50 的记录       ✅
  no match                      → "昨天没有「交通」财务记录"   ✅
  sort=amount_desc + limit=2    → 正确排序+截断               ✅

Mode C:
  "最近吃饭花了多少钱" (LLM不可用) → 降级为 today 查询       ✅
  empty query input             → 错误提示                     ✅

Regression:
  记录 + 删除 + 中文数字        → 全部正常                     ✅
```
