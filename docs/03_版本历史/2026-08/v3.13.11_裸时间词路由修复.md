# v3.13.11 — 裸时间词路由修复（Phase 7）

> **日期**：2026-08-22 ｜ **类型**：🐛 修复 —— 裸时间词（本月/本周/今天/昨天）不再默认财务查询

## 背景

Phase 7 测试发现：输入裸时间词（"本月"）被默认路由到财务查询（"本月共24笔支出"），
而非时间回查摘要。Fix B 的时间回查预路由 (I) 只匹配"时间词 + 发生了什么/做了什么事"，
未覆盖"本月"这类无动词的裸时间词。

## 根因

预路由 (I) 的 `_TIME_RECALL_RE` 要求时间词后跟回查动词（发生了什么/干了什么…）。
裸"本月/本周/今天/昨天"无动词 → (I) 不触发 → 落到 3b → 被判 query+finance → 财务查询。

## 修复内容

### `脑.py` — 预路由 (I)

1. **支持裸时间词**：`_TIME_RECALL_RE` 新增锚定的裸时间词分支
   （`^(今天|昨天|前天|本周|上周|本月|这个月|上个月|上周三…)$`），
   整句仅为时间词时直接触发时间回查。
2. **排除规则扩展**：`花了|消费|收入|支出` 加入排除——含财务词的输入（"本月花了多少"）
   仍走财务查询，不被 (I) 劫持（原有 日程/待办/提醒/记账 排除保留）。
3. **`_extract_memory_time_expr` 补"上个月"**。

### `记忆/记忆引擎.py`

- `_date_range_for` 新增 `last_month`/上个月 范围（时间回查"上个月"需要）。
