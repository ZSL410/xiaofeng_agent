# v3.2.0 — 模糊删除 + 路由性能优化

**日期**：2026-06-22  
**类型**：新功能 + 性能优化  
**版本**：v3.1.4 → v3.2.0

## 变更摘要

新增按自然语言描述删除提醒的能力（模糊删除），同时优化 LLM 路由超时和模型降级策略。

## 模糊删除

- `delete_reminder_by_query(query)`：按内容+时间双维度评分匹配
- 唯一匹配直接删除，多个候选列出让用户选择
- `process_command` 自动检测删除关键词并路由

## 路由优化

- 超时：5s → 8s
- 模型降级链：`qwen2.5:7b`(8s) → `qwen2.5:3b`(5s) → 关键词匹配
- 新增 `delete_reminder` 路由动作和 `DELETE_KW` 关键词降级
