# 晓风架构设计

## 模块划分

```
用户输入（文字/语音）
        ↓
      脑.py（路由层：3b 紧凑路由优先 → 7b 降级 → 关键词兜底 + 置信度门控 + 确认状态机）
        ↓
   ┌────┴────┐
   ↓              ↓
日程模块         财务模块
(schedule)      (finance)
   ↓              ↓
记忆引擎         回复层（脑.py 内 _generate_tool_reply，统一回复风格 + 追问）
(memory)                 ↓
                   语音输出（嘴巴.py）
```

## 器官隐喻

| 模块 | 路径 | 职责 |
|------|------|------|
| 脑.py | `00_核心主体/脑.py` | 主入口，编排对话循环、LLM 路由 |
| 耳朵.py | `00_核心主体/器官/耳朵.py` | Vosk 离线语音识别输入 |
| 嘴巴.py | `00_核心主体/器官/嘴巴.py` | Edge TTS 语音合成输出 |
| 手.py | `00_核心主体/器官/手.py` | 动态工具调用分发器 |

## 路由架构

```
_route_with_3b()  ← 主路由（v3.9.0，快速语义分类 <3s）
  └─ LLM(qwen2.5:3b, 3s超时) → intent {intent, target, params, confidence}
       ├─ confidence ≥ 0.6 → 直接执行
       └─ 失败 / confidence < 0.6 → 降级到遗留路由链

_route_intent()  ← 降级路由链
  ├─ LLM(qwen2.5:7b, 8s超时) → intent {tool, action, params, confidence}
  │    ├─ confidence ≥ 0.6 → 直接执行
  │    └─ confidence < 0.6 → 向用户确认
  ├─ 7b 超时 → 降级 qwen2.5:3b (5s超时)
  └─ 3b 也失败 → 关键词匹配兜底
```

> **说明**：v3.9.0 起，**qwen2.5:3b 紧凑路由为主路由**，优先保证响应速度（<3s）；
> qwen2.5:7b 作为**降级模型 + 聊天/对话模型**，在 3b 判定失败或置信度不足时兜底。

## 关键设计决策

| 决策 | 理由 | 日期 |
|------|------|------|
| 路由层从正则改为 LLM 驱动 | 应对自然语言变体，覆盖口语表达 | 2026-06-19 |
| 语音容错（教→叫、纯数字+叫） | 语音识别常见偏差 | 2026-06-20 |
| 低置信度确认机制 | 避免错误解析盲目执行 | 2026-06-21 |
| 修正机制改为删除+重建 | 避免时间累加错误 | 2026-06-22 |
| 模型降级链（3b 优先→7b→关键词） | 3b 保证响应速度，7b 兜底准确度 | 2026-06-22 → v3.9.0 反转优先顺序 |
| 数据提炼 + 遗忘机制 | 从历史中学习并自我清理 | 2026-06-22 |

## 数据流

```
用户输入 → 文本规范化 → 残留过滤 → 删除否定检查 → 确认状态机
  → 3b 路由(主) / 7b 路由(降级) → 工具分发(手.py call_tool) → 模块执行
  → 回复层(_generate_tool_reply, 统一风格+追问) → 语音/文字输出
                                    ↓
                              记忆引擎(短期/长期/facts/patterns)

[外部] 拟态前端 ←─ HTTP API (:5001) ─→ 晓风后端
```
