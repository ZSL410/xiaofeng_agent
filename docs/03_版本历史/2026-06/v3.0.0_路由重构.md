# v3.0.0 — 路由层重构（正则→LLM）⚠️ BREAKING

**日期**：2026-06-20  
**类型**：架构变更（Breaking）  
**版本**：v2.7.2 → v3.0.0

## 变更摘要

路由层从固定关键词规则引擎重构为 LLM 驱动架构。属于核心调度逻辑的范式变更，因此升级主版本号。

## 核心改动

### `_route_intent()` 函数
- 调用 `qwen2.5:7b`（`/api/generate`, temperature=0）
- 返回 JSON 意图标签 `{"tool":"日程|财务|聊天"}`
- 3 秒超时，失败返回 None 由调用方降级处理
- 输出清洗：剥离 markdown 代码块、正则兜底匹配、JSON 解析三重保障

### 关键词降级
- 原 `SCHEDULE_KW` / `FINANCE_KW` 关键词匹配逻辑保留
- 仅在 LLM 路由失败时启用，确保可靠性

### 工具注册表
- `TOOLS` 列表描述各工具功能和典型示例
- 作为 LLM 路由判断依据
