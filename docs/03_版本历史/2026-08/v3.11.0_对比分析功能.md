# v3.11.0 — 对比分析功能（Phase 5）

> **日期**：2026-08-15 ｜ **类型**：⚡ 新功能 —— 数据对比分析

## 背景

晓风能记账、管日程、记记忆，但还**不能"读懂"这些数据**——用户问"本周花了多少比上周多吗"、
"这个月最大的开支是什么"，只能得到单调的账单罗列。Phase 5 为晓风补上**跨期对比与统计洞察**能力，
让数据回答"趋势"而不只是"记录"。

## 新增功能

| # | 功能 | 触发示例 | 输出 |
|---|------|----------|------|
| 1 | 周对比 | 本周花了多少？比上周多吗？ | 本周共花费213元，上周共花费95元，比上周多124% |
| 2 | 月对比 | 本月开销比上个月大吗？ | 本月共花费373元，上月共花费339元，比上月多10% |
| 3 | 分类对比/汇总 | 这个月吃饭花了多少？比上个月呢？ | 本月餐饮支出166元，上月餐饮支出166元，与上月持平 |
| 4 | 最大开支 | 这个月最大的开支是什么？ | 最大开支：日常消费 30元 (2026-08-12) |
| 5 | 高频活动 | 我最近经常做什么？ | 1. 喝咖啡 (26次)、2. 吃饭 (16次)… |
| 6 | 消费时段 | 我一般什么时候花钱最多？ | 凌晨 (56%)、深夜 (36%)、上午 (5%) |
| 7 | 周总结 | 这周我做了什么？ | 本周总结：共花费213元，主要支出在生活(143元)、餐饮(41元)，共9项日程，完成6次会议… |

无数据时统一友好提示：**「这段时间还没有数据记录哦」**。

## 变更内容

### `记忆引擎.py` — 新增 Phase 5 分析函数（约 470 行）

数据源（跨模块只读，不做写回）：
- 财务：`01_工具模块/财务模块/local_archive.json`
- 日程：`01_工具模块/日程模块/events.json` / `todos.json`
- 记忆：`memory.json` + `对话归档.json`

新增函数：
- `compare_week_over_week()` — 本周 vs 上周支出（金额/差额/百分比）
- `compare_month_over_month()` — 本月 vs 上月支出
- `get_category_summary(period)` — 按分类统计支出（复用 Phase 3 `_resolve_date_range` 时间解析）
- `compare_category_across_periods(cat, base, compare)` — 单分类跨期对比（"吃饭 vs 上个月"）
- `get_highest_expense(period)` — 时段内最大单笔开支
- `get_frequent_activities(limit)` — 高频活动（记忆实体标签 + 财务来源 + 对话归档三源合并，按显示名去重）
- `get_spending_pattern(period)` — 消费时段分布（凌晨→深夜 7 时段 + 百分比）
- `generate_weekly_summary()` — 本周综合总结（财务 + 日程 + 记忆活动）
- `run_analysis(user_input)` — **统一下发入口**：关键词 → 具体分析函数 → 自然语言回复；非分析输入返回 `None`

关键设计：
- 类别检测要求**消费语境**（"我喜欢喝拿铁"不触发分析，防误判）
- 记忆记录/日程添加/删除等强意图内置排除（防劫持）
- 高频活动按显示名合并（"饭"+"吃饭" → "吃饭"，避免重复条目）

### `脑.py` — 路由集成（v3.11.0）

新增「分析」意图，四级保障：
1. **确定性预路由**（最高优先，v3.11.0 新增）：`_ANALYSIS_RE` 分析信号词 + `_ANALYSIS_EXCL_RE` 排除词
   （记住/添加/删除/搜索/提醒…），命中即 `run_analysis`——绕过 LLM，保证验收用例稳定命中
2. **3b 路由**：`_ROUTE_PROMPT_3B` 新增 `analyze` 意图（含"分析优先级"规则：分析词必须优先于财务词）
   + 3b 分发分支 `intent_3b == "analyze"` → `run_analysis`
3. **7b 路由**：`_ROUTE_PROMPT_V2` 新增「### 对比分析(analyze)」工具说明 + 工具白名单 + 主分发
   `elif tool == "分析"` → `run_analysis` + `_last_router_result` 上下文延续
4. **降级关键词匹配**：新增分析关键词分支（置于财务之前，"比上周"的分析查询也含"花了"）

VERSION 常量 `3.10.11 → 3.11.0`。
