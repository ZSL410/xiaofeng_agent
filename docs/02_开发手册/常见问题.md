# 常见问题

## 启动问题

**Q: Ollama 连接失败？**  
A: 检查 `模型.json` 中 `ollama_host` 配置。WSL 下应指向 Windows 宿主 `http://localhost:11434`。确保 Windows 端 `ollama serve` 已运行。

**Q: 语音识别失败？**  
A: Vosk 模型未下载或路径不对。下载 `vosk-model-cn-0.22` 放到 `00_核心主体/` 目录。模型缺失时自动回退到模拟文本。

**Q: 残留命令被读取？**  
A: v3.1.4 已强化过滤。如仍有漏网，在 `脑.py` 的 `_RESIDUAL_PATTERNS` 中添加对应的正则模式。

## 功能问题

**Q: 提醒时间不对？**  
A: 检查 `模型.json` 中 LLM 是否正确。"X分钟后"始终是分钟。修正时间说"不是X是Y"而非重复创建。

**Q: 删除提醒失败？**  
A: 可以按序号删除（"删除任务1"），也可以模糊删除（"把泡咖啡那个删掉"）。先说"显示待办"查看列表。

**Q: 智能播报不生效？**  
A: 检查 `模型.json` 中 `use_smart_reminder` 是否为 `true`。Ollama 超时（3s）会自动降级为通用文案。

## 开发问题

**Q: 如何启用详细日志？**  
A: `DEBUG=1 python 00_核心主体/脑.py`

**Q: 如何重置数据？**  
A: 删除 `todos.json`、`events.json`、`短期记忆.json`、`长期记忆.json` 即可。程序会自动重建空文件。

**Q: 为什么版本号跳过了 v3.4.x？**  
A: 版本号按功能层级递增。v3.5.0 新增了完整的记忆管理子系统（提炼+遗忘），v3.6.0 是文档体系重构。
