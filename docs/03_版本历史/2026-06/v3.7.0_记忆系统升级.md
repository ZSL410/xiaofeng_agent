# v3.7.0 记忆系统升级

> **日期**：2026-06-24 ｜ **类型**：架构升级 ｜ **影响范围**：记忆系统

## 核心变更：从被动存储到主动学习

记忆系统从 v3.6.0 的"被动存储用户陈述"升级为"主动学习六步闭环"：

```
用户陈述 → LLM 语义提取 → Python 校验写入 → 分类存储
    → 衰减调度自动维护 → 分层注入 Prompt → 主动预判
```

## 详细变更

### 1. 数据结构重构：三文件分离

| v3.6.0 | v3.7.0 |
|--------|--------|
| 全部存储在 `长期记忆.json` | `facts.json`（事实）+ `patterns.json`（习惯）+ `context_summary.txt`（摘要） |

- **facts.json**：用户静态事实（偏好/身份/技能等），支持 `pinned` 固定注入
- **patterns.json**：动态行为习惯，含 `confidence` 置信度和 `archived` 归档标记
- **patterns_archive.json**：过期习惯归档存储
- **context_summary.txt**：LLM 生成的会话摘要（每 10 轮更新）
- 新增 `embedding`、`related_to`、`relation_types` 扩展预留字段

### 2. 记忆引擎重写

**新增接口**：

| 接口 | 功能 |
|------|------|
| `add_fact()` | LLM 提取事实后写入 facts.json |
| `add_pattern()` | 统计提炼习惯后写入 patterns.json |
| `update_confidence()` | 置信度动态调整 |
| `update_importance()` | 事实重要性动态调整 |
| `get_pinned_facts()` | 获取固定事实（用于必注入） |
| `get_high_confidence_patterns()` | 获取高置信度习惯（用于按需注入） |
| `get_context_summary()` | 获取会话摘要 |
| `rebuild_context_summary()` | LLM 重新生成摘要 |
| `run_decay()` | 执行置信度衰减 |
| `archive_expired()` | 归档过期记忆 |
| `merge_similar_facts()` | 合并相似事实 |
| `get_memory_stats()` | 记忆系统统计信息 |
| `build_injection_context()` | 构建分层 Prompt 注入上下文 |

**向后兼容**：
- `decay_patterns()`、`reject_pattern()`、`boost_pattern()` 保留不变
- `load_long_term()` / `save_long_term()` 内部重定向到新文件
- 首次启动自动从 `长期记忆.json` 迁移数据并备份

### 3. 衰减调度独立模块

新文件 `00_核心主体/记忆/衰减调度.py`：

- `scheduler_check()`：主程序启动时自动调用
- `run_daily_decay()`：每日衰减核心逻辑（`last_trigger > 30天 → confidence *= 0.95`）
- `manual_cleanup()`：用户手动触发"整理记忆"
- `get_decay_status()`：衰减状态查询
- 事件日志：`on_pattern_formed` / `on_pattern_decayed` 记录到 `memory_events.log`
- 支持 `--force` / `--cleanup` 命令行参数独立测试

### 4. 检索注入分层策略

| 层级 | 内容 | 触发条件 |
|------|------|----------|
| 必注入 | `context_summary.txt` + pinned facts（≤5 条） | 始终 |
| 按需注入 | 高置信度 patterns（≤5 条） | 用户提及"提醒/定时/日程/叫我"等关键词 |
| Token 控制 | 注入总上限 2000 tokens | 超限按 importance/confidence 降序截断 |

### 5. LLM 辅助记忆提取

- 对话中自动检测记忆材料（通过 `_route_intent` 扩展或独立提取 prompt）
- LLM 输出结构化 JSON：`{"type":"fact/pattern","content":"...","category":"...","importance":0.8}`
- Python 层校验：分类合法性 + 重复检测 + 格式完整性
- 相似度 > 0.85 自动合并

### 6. 存储抽象预留

```python
class MemoryStorage(ABC):
    def read(self, key): ...
    def write(self, key, value): ...
    def search(self, query): ...
    def delete(self, key): ...
```

v3.7.0 默认使用 JSON 文件存储，为后续 SQLite / 向量数据库替换预留接口。
