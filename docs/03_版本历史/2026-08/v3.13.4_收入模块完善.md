# v3.13.4 — 收入模块完善

> **日期**：2026-08-16 ｜ **类型**：⚡ 功能 —— 收入查询 + 收支统计 + 收入趋势

## 背景

v3.13.3 已修复「支出查询把收入计进合计」的核心 bug。本次在此之上完善收入的完整能力：
专门的收入查询、收入来源汇总、最大收入来源、收支明细统计、收入趋势分析。

## 新增能力

### `finance_module.py` — `_execute_query`

1. **来源分组汇总**：查询含「来源/有哪些/分别/都花在哪」语义时，按来源聚合展示
   （「收入来源有哪些」→ 逐来源列出金额）。含「最大/最多/最高」+「来源」时
   输出金额最大的来源（「最大收入来源」）。
2. **收支明细统计**：「查看所有财务数据」类查询（全量模式）输出
   「共N笔记录（支出X笔，合计A元；收入Y笔，合计B元）」。
3. **措辞按方向区分**：默认汇总「共N笔支出/收入，合计X元」；max/min 聚合
   「最大/最小开支」→ 收入方向改「最大/最小收入」。
4. **单笔详情分支限定支出模式**：收入/全量查询不再被「仅此一笔」详情覆盖，
   改用标准的「本月共1笔收入，合计5000元」措辞。

### `finance_module.py` — 新增收入统计接口

- `get_income_total(date_range=None)` — 指定范围收入总额（默认今天）
- `get_income_sources(date_range=None)` — 列出收入来源及金额（按金额降序）
- `get_income_trend(periods=3)` — 最近 N 个月收入聚合 + 方向判断（上升/下降/平稳）

### `脑.py` — 新增预路由 (M) 收入查询

- 收入词（收入/赚了/进账/工资/奖金/红包等）+ 查询语义（多少/来源/总/本月/昨天/趋势等）
  → 确定性路由到 `query_finance`（income 方向），绕过 3b 对「这个月收入」「总收入」
  等无「多少」表达可能误判 chat/clarify 的问题。
- 排除：含金额（"收入工资5000元"→记账）、记住/记下（"记住我的收入"→记忆）。
- 「收入趋势/走势」→ 直接调用 `get_income_trend` 输出趋势图。
