# v3.3.0 — 数据提炼引擎

**日期**：2026-06-22  
**类型**：新功能  
**版本**：v3.2.1 → v3.3.0

## 变更摘要

新增 `数据提炼.py` 模块，扫描历史待办/日程，自动提炼用户行为模式。三种分析维度：时段习惯、固定间隔、内容关联。

## 新增文件

`00_核心主体/记忆/数据提炼.py` — `refine()` 主入口

## 三种分析维度

| 类型 | 字段 | 说明 | 最低样本 |
|------|------|------|----------|
| `time_based` | content, time_range, frequency | 同一内容在相似时间段重复（60min窗口聚类） | ≥2次 |
| `interval` | content, interval_minutes, occurrences | 同一内容以固定间隔创建（±25%容差） | ≥3次 |
| `association` | from, to, frequency | 内容A创建后频繁跟随内容B | ≥2次 |

## 集成方式

- **每日自动提炼**：启动时 `_try_daily_refine()` 检查 `last_refined`，每天一次
- **手动触发**：输入 `提炼规律` / `分析习惯`

## 输出格式

```json
{
  "patterns": [
    {"type": "time_based", "content": "泡咖啡", "time_range": "08:00-09:00",
     "frequency": 3, "confidence": 0.80}
  ],
  "last_refined": "2026-06-22T12:00:00"
}
```
