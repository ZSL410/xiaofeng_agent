# v3.13.10 — 时间回查摘要（Phase 7, Fix B）

> **日期**：2026-08-22 ｜ **类型**：⚡ 改进 —— 时间回查"回答生成层"：分组计数摘要替代原始记录 dump

## 背景

Phase 7 测试发现：「上周三发生了什么」返回的是原始记录列表
（`[2026-08-12] (event) 记账` 等泛化标题），无分组、无金额、无可读性。

## 修复内容

### `记忆/记忆引擎.py`

新增 `format_time_recall(records, time_label)`：
- 按 `_memory_domain`（复用 Fix A）分组：财务/日程/待办/事实/情绪/其他
- 财务：从 detail 解析金额（`花费X元`）求和 → 「记账 N 笔，共 X 元」
- 日程/待办：计数 → 「添加日程 N 个」「添加待办 N 个」
- 事实：计数 + 列出内容（最多 5 条）
- 无记录 → 「{time_label}没有查到记录哦」
- 辅助 `_sum_amounts(records)`：累加可解析金额

### `脑.py`

- 预路由 (I)（时间回查）：改用 `format_time_recall`，`search_by_time` limit 10→200
  保证计数准确；检索提升只作用于前 10 条避免置信度膨胀。
- 3b query+memory 路径（时间/记忆查询镜像）：同样改用 `format_time_recall`。
