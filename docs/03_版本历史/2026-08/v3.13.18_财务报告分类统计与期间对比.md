# v3.13.18 — 财务报告 Phase 2：分类统计 + 期间对比 + 交易明细

> **日期**：2026-08-25 ｜ **类型**：⚡ 增强 —— `generate_report` 从"仅收支汇总"扩展为四段式完整财务报告（纯 Python 聚合，无 LLM）

## 背景

v3.13.17 完成 `generate_report()` Phase 1（收支汇总 + Word 生成），用户反馈"内容太简单（只有合计，没有分解）"。
Phase 2 在**不改变函数签名**（`data=None, output_dir=None`）的前提下，为报告追加三段结构化内容。

## 修复/增强内容

### `01_工具模块/财务模块/finance_module.py` — 新增 4 个辅助函数 + `generate_report` 重写

| 函数 | 职责 |
|------|------|
| `_compute_category_breakdown(records)` | 按 `category` 分组支出金额、计算占比（占总支出 %），按金额降序返回 `{分类: {amount, percentage}}`。仅统计 `type=="expense"`，收入不计入 |
| `_get_period_comparison(records, now=None)` | 计算**本周 vs 上周**、**本月 vs 上月**的支出对比（当前期/上期/变化百分比）。统计口径与记忆引擎 `_finance_in_range` 一致（仅支出）；日期范围与 `_date_range_for` 一致（本周一~周日 / 上月自然整月）。`now` 参数供测试注入固定日期 |
| `_format_percent_change(percent)` | 百分比显示格式化：`None`→"—"（上期为 0 无法计算）、正数"+X%"、负数"-X%"、0→"0%" |
| `_build_detail_table(records, limit=50)` | 按 date 降序 + time 升序排序，截取最近 `limit` 条（默认 50） |

`generate_report()` 文档结构升级为四段式：

```
每日财务报告
生成时间：YYYY-MM-DD HH:MM

一、收支汇总      总支出 / 总收入 / 结余
二、分类统计      表格：分类 | 金额 | 占比（按金额降序）
三、期间对比      表格：对比项 | 当前期 | 上期 | 变化（周/月两行）
四、交易明细      表格：日期 | 时段 | 分类 | 来源 | 金额（最近50条）
```

- 全部新增段落均为 **additive**，Phase 1 的收支汇总内容保留（仅顺序调整为 总支出→总收入→结余，与计划模板一致）。
- 报告数据范围：默认传入的 `data`（即 `load_data()` 全量），与 Phase 1 口径一致。
- 使用 `python-docx` 内置 `Light Grid Accent 1` 表格样式；标题与正文仍无 emoji（Word/WPS 方块兼容）。
