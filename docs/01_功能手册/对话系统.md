# 对话系统

## 概述

晓风的对话系统以 `脑.py` 为核心，采用 LLM 驱动的意图路由架构。用户输入（文字或语音）经规范化处理后，由路由层判定意图并分发到对应工具模块。

## 核心流程

1. **文本规范化**：`input()` 读取 → 折叠多余空格 → 移除中文字符间空格
2. **残留过滤**：12 条正则模式拦截终端残留命令
3. **确认状态机**：低置信度提醒先确认再执行
4. **LLM 路由**：qwen2.5:7b（8s）→ 3b（5s）→ 关键词兜底
5. **工具分发**：`手.py` 动态 import 目标模块
6. **语音输出**：文字 + Edge TTS 语音双通道输出

## 路由意图类型

| 意图 | action | 说明 |
|------|--------|------|
| 日程提醒 | `add_reminder` | 创建带时间的提醒待办 |
| 修正提醒 | `correct_reminder` | 纠正上次提醒的参数 |
| 删除提醒 | `delete_reminder` | 按描述模糊删除提醒 |
| 日程管理 | `manage` | CRUD 日程/待办 |
| 财务 | (无) | 记账/查账自然语言处理 |
| 聊天 | (无) | 通用对话 |

## 语音交互

- 输入 `v` → 5 秒录音 → Vosk 离线识别 → 转为文字
- 语音识别容错：`教`→`叫`、中文字符间空格修复
- 输出：Edge TTS 合成语音 + 终端文字

## 确认机制

当 LLM 路由置信度 < 0.6 且意图为 `add_reminder` 时：
- 打印 `🤔 你是想说「…」吗？`
- 等待用户确认（是/不是）
- 修正模式：`不是X是Y` → 自动删除旧提醒重建
