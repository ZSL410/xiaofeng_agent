# 置信度权重

> 记录系统中各预测/解析的准确率，用于调整模型行为。

## 路由层

| 组件 | 当前配置 | 说明 |
|------|----------|------|
| 主路由模型 | qwen2.5:3b | 3b 紧凑路由优先（v3.9.0），快速语义分类 <3s |
| 主路由超时 | 3s | qwen2.5:3b |
| 降级模型 | qwen2.5:7b | 3b 失败/置信度不足时兜底 + 聊天对话 |
| 降级模型超时 | 8s | qwen2.5:7b |
| 遗留路由链超时 | 5s | 降级链中 3b 再次尝试的二次超时 |
| 低置信度阈值 | 0.6 | 3b ≥0.6 直接执行；降级路径 <0.6 触发确认 |
| 修正意图最低置信度 | 0.85 | 纠错表达天然高置信度 |

## 数据提炼

| 组件 | 当前配置 | 说明 |
|------|----------|------|
| 时间聚类窗口 | 60 分钟 | time_based 模式的时间窗口 |
| 间隔容差 | ±25% | interval 模式的允许偏差 |
| 遗忘阈值 | 0.3 | 置信度低于此值且长期未触发 → 归档 |
| 衰减速率 | ×0.95/次 | 30 天未触发后每次衰减检查乘以 0.95（≈5%） |
| 归档条件 | conf < 0.3 且 > 60 天 | 标记 archived 并移入 patterns_archive.json |
| 拒绝惩罚 | -0.30 | 用户拒绝时立即降低 |
| 确认奖励 | +0.10 | 用户确认时提升（上限 0.95） |

## 提醒解析

| 组件 | 说明 |
|------|------|
| 正则解析 | 首选（快速、精确） |
| LLM 解析 | 降级（覆盖自然口语） |
| 1 分钟兜底 | 最终保底（确保提醒不丢失） |
