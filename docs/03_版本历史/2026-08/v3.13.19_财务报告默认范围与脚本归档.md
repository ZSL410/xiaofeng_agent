> **日期**：2026-08-25 ｜ **类型**：🐛/🧹 —— 修正 `generate_report` 默认范围（今日/近3天）+ 归档旧版独立 `generate_report.py`

## 背景

v3.13.18 报告默认统计**全部 67 条记录**，与"每日财务报告"的定位不符——用户期望：
- **汇总**看今天（今日无数据则取最近有数据日）
- **交易明细**看近 3 天
- **期间对比**用全量数据（本周vs上周、本月vs上月）
- **分类统计**参考今日 + 近 3 天

同时，`01_工具模块/财务模块/generate_report.py`（旧版 LLM 总结独立脚本）已无人调用，纯属遗留，应归档。

## 修复/增强内容

### `01_工具模块/财务模块/finance_module.py` — 默认范围 + scope 参数

**新增日期范围辅助函数**（v3.13.19）：

| 函数 | 职责 |
|------|------|
| `_week_bounds` / `_last_week_bounds` / `_month_bounds` / `_last_month_bounds` | 本周/上周/本月/上月 (start, end)，与记忆引擎 `_date_range_for` 口径一致 |
| `_records_in_range(records, start, end)` | 按闭区间筛选记录 |
| `_get_default_date_range(records, now=None)` | 计算默认范围 `(report_date, start_3d, end_3d)`：report_date = 今天有记录则为今天，否则为最近有数据日；近三天 = [report_date-2, report_date] |

`_get_period_comparison` 重构为复用上述 bounds 辅助（行为不变，测试 69 项通过）。

**`generate_report(data=None, output_dir=None, scope="default")`** — 新增 `scope` 参数：

| scope | 汇总 | 明细 | 分类 | 期间对比 |
|-------|------|------|------|----------|
| `"default"`（默认） | 今日（无则最近有数据日） | 近 3 天（≤30 条） | 今日+近 3 天 | 全量数据 |
| `"today"` | 严格今日 | 今日 | 今日 | 全量数据 |
| `"week"` | 本周 | 本周（≤50） | 本周 | 全量数据 |
| `"month"` | 本月 | 本月（≤50） | 本月 | 全量数据 |
| `"all"` | 全部 | 全部（≤50） | 全部 | 全量数据 |

- 非法 scope 回退 `"default"`。
- 报告四段式顺序调整为：**一、收支汇总 → 二、交易明细 → 三、期间对比（全量数据）→ 四、分类统计**。
- 页眉与汇总区标注统计范围（如 `2026-08-25（今日）` / `2026-08-24（最近有数据日）` / `全部数据`）。
