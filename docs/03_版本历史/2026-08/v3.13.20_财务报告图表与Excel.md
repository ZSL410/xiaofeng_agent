# v3.13.20 — 财务报告 Phase 3：图表 + Excel 导出

> **日期**：2026-08-25 ｜ **类型**：⚡ —— `generate_report` 新增 `format` 参数（docx/excel/both）、Word 报告插入收支趋势图表（matplotlib）、新增 Excel 四工作表导出（openpyxl）

## 背景

v3.13.19 的四段式 Word 报告只有表格数据，缺少直观的收支走势预览；同时用户希望数据可复用为 Excel 工作簿。Phase 3 在 `finance_module.py` 内新增 matplotlib 图表与 openpyxl Excel 导出，报告结构升级为**五段式**。

## 修复/增强内容

### `finance_module.py` — 图表生成（matplotlib）

| 函数 | 职责 |
|------|------|
| `_setup_chinese_font()` | 注册中文字体（候选 `/mnt/c/Windows/Fonts/` 与 `C:\Windows\Fonts` 下的 simhei.ttf / msyh.ttc / simsun.ttc），配置 `rcParams['font.sans-serif']` 与 `axes.unicode_minus=False`；无字体不抛异常 |
| `_aggregate_daily(records, days, end_date)` | 按日聚合支出/收入/结余，生成覆盖最近 N 天的**连续日期序列**（无数据日补 0，空数据返回 `[]`）；窗口终点默认今日、今日无记录则取最近有数据日 |
| `_generate_chart_image(records, chart_type, days, output_dir, end_date)` | 渲染图表 PNG（Agg 无界面后端）：`line` 折线（趋势）/ `bar` 柱状（对比），三指标支出/收入/结余；matplotlib 缺失或渲染失败返回 `None`（不抛异常） |
| `_generate_trend_chart(records, days=7)` | 折线图包装 |
| `_generate_comparison_chart(records, days=7)` | 柱状图包装 |

**图表展示规则**：近 7 天 + 近 30 天，各生成 折线 + 柱状 共 4 张；数据源为全量记录按日聚合的支出/收入/结余。

### `generate_excel(data, output_path, scope)` — Excel 导出（openpyxl）

- 四工作表：**Summary**（收支汇总）/ **Category**（分类统计+占比）/ **Comparison**（期间对比）/ **Detail**（交易明细全量，日期降序）
- 复用 `_resolve_report_windows` 窗口解析，口径与 `generate_report` 完全一致
- openpyxl 缺失返回 error（不崩溃）

### `generate_report` 重构

- 新增 `format` 参数：`"docx"`（默认，Word 含图表）/ `"excel"`（仅 Excel）/ `"both"`（Word + Excel 同时生成）
- 抽取 `_resolve_report_windows(data, scope)` 统一窗口解析（generate_report / generate_excel 共用，行为不变）；抽取 `_build_report_docx` 负责 Word 构建
- 报告五段式：**一、收支汇总 → 二、交易明细 → 三、收支趋势图表（新，插在期间对比表前）→ 四、期间对比（全量数据）→ 五、分类统计**
- 返回新增 `docx_path` / `excel_path`；`file_path` 语义：docx 时指 docx、excel 时指 xlsx、both 时指已成功生成的产物

### 优雅降级 / 临时文件清理

| 场景 | 行为 |
|------|------|
| matplotlib 缺失或图表渲染失败 | 跳过图表段，注明「（图表生成失败，请查看表格数据）」，报告照常生成 |
| openpyxl 缺失 + `format="excel"` | 返回 error，提示缺少依赖 |
| openpyxl 缺失 + `format="both"` | **部分成功**：返回 Word（status=success），message 提示 Excel 导出失败 |
| 图表临时图片 | 写入 `tempfile.TemporaryDirectory()`，Word 保存后自动清理，`每日财务/` 无残留 |
