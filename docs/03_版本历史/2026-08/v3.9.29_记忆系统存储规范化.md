# v3.9.29 — 记忆系统存储规范化

> **日期**：2026-08-07 ｜ **类型**：🎯 存储标准化（与财务 v3.9.24、日程 v3.9.25 对齐）

## 背景

财务模块（v3.9.24）与日程模块（v3.9.25-28）已完成记录标准化。本版本将统一架构应用到记忆系统：`facts.json`/`patterns.json` 结构不一致、无法按时间/时段查询、缺少 mood/tags/importance 等元数据的问题。

## 变更内容

### 1. 统一记忆记录结构（15 字段，`memory.json`）

新增 `00_核心主体/记忆/memory.json`，统一存储所有记忆条目：

```json
{
  "id": "memory_20260805_1430_a3f8x2",
  "type": "memory",
  "subtype": "event",
  "date": "2026-08-05",
  "time": "14:30",
  "datetime": "2026-08-05T14:30:00",
  "period": "下午",
  "title": "讨论记忆系统规范",
  "content": "下午讨论了记忆系统的存储规范设计",
  "detail": "和用户一起讨论了记忆系统的定位和字段设计，确认了15字段标准",
  "mood": "专注",
  "tags": ["设计", "记忆系统", "规范"],
  "importance": 8,
  "created_at": "2026-08-05T14:30:00",
  "updated_at": null
}
```

**subtype 枚举**：`event`（具体事件）/ `fact`（事实信息）/ `habit`（行为习惯）/ `reflection`（反思感悟）。

### 2. 新增辅助函数（`记忆引擎.py`）

| 函数 | 说明 |
|------|------|
| `_generate_id()` | `memory_{YYYYMMDD}_{HHMM}_{6字符}` |
| `_get_period(time_str)` | 时段标签（与财务/日程一致） |
| `_generate_content(period, title)` | `{period}{title}` → "下午讨论记忆系统规范" |
| `_normalize_date()` / `_normalize_time()` | 统一日期/时间格式（空时间默认 12:00） |
| `_sort_records()` | date 降序 + time 升序 |
| `_migrate_to_standard_format()` | facts/patterns → memory.json 一次性迁移（幂等） |
| `_date_range_for()` | 时间筛选词 → 日期范围 |

### 3. 新增接口

- **`add_memory_event(title, detail, mood, tags, importance, subtype)`** — 创建丰富记忆条目，供工具模块调用
- **`load_memories()`** — 加载统一记忆库（自动迁移 + 自动排序）
- **`get_memories(subtype, time_filter, period, limit)`** — 按 subtype/时间范围/时段查询

### 4. 现有接口升级

- `add_fact()` / `add_pattern()`：写入原文件同时**同步到 memory.json**（`_sync_fact_to_memory` / `_sync_pattern_to_memory`）
- facts → subtype `fact`；patterns → subtype `habit`（pattern 元数据写入 detail）

### 5. 工具模块集成

- **财务模块**：记账成功后调用 `add_memory_event`（title="记账"，detail=交易详情，tags=["财务", 分类]）
- **日程模块**：添加日程/待办后调用 `add_memory_event`（title="添加日程"/"添加待办"，detail=描述）
- 记忆记录失败不影响主流程（try/except 静默降级）
