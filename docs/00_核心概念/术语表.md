# 术语表

| 术语 | 英文 | 含义 |
|------|------|------|
| 晓风 | Xiaofeng | 项目名称，AI 助手人格 |
| 脑 | Brain | 主入口模块，编排对话循环和路由 |
| 耳朵 | Ear | 语音识别输入模块（Vosk） |
| 嘴巴 | Mouth | 语音合成输出模块（Edge TTS） |
| 手 | Hand | 动态工具调用分发器 |
| 器官 | Organ | 核心功能模块的统称 |
| 拟态 | Mimetic | 桌宠形态的 GUI 前端 |
| 路由 | Routing | LLM 驱动的意图分类 → 工具分发 |
| 工具 | Tool | 可被路由层调用的功能模块（日程/财务） |
| 日程 | Schedule | 事件管理 + 待办管理 + 提醒 |
| 待办 | Todo | 带到期时间的提醒事项 |
| 事件 | Event | 带日期的日程安排 |
| 短期记忆 | Short-term Memory | 最近 20 轮对话历史 |
| 长期记忆 | Long-term Memory | 跨会话的用户信息和行为模式 |
| 置信度 | Confidence | LLM 路由解析的确定程度 (0-1) |
| 修正 | Correction | 用户纠正已创建的提醒参数 |
| 提炼 | Refinement | 从历史数据中提取行为模式 |
| 遗忘 | Decay | 对过期/被拒绝的模式执行置信度衰减 |
| 模式 | Pattern | 数据提炼发现的行为规律 |
