# 日程模块

## 概述

`01_工具模块/日程模块/schedule_module.py` — 日程事件管理、待办事项管理、定时提醒，带后台守护线程每 30 秒检查到期提醒。

## 核心功能

### 1. 自然语言提醒

```
"提醒我5分钟后喝水"     → 创建待办：喝水(now+5min)
"26叫我"               → 当前小时:26 提醒
"明天8点叫醒我"         → 明天 08:00 提醒
"半个小时后洗衣服"      → now+30min 提醒
```

时间解析三级降级链：正则 → LLM → 1 分钟后兜底

### 2. 日程事件管理

```
"添加会议明天下午3点"   → 创建日程事件
"删除日程1"            → 删除 ID=1 的日程
"显示今天的日程"        → 列出今日日程
```

支持重复：每天/每周/每月

### 3. 待办事项管理

```
"添加任务买牛奶"        → 创建待办
"完成任务1"            → 标记完成
"删除任务1"            → 删除待办
"显示待办"             → 列出未完成待办
```

### 4. 模糊删除（v3.2.0）

```
"把两个小时的那个定时删掉"  → 按时间描述匹配并删除
"删除泡咖啡那个提醒"        → 按内容匹配并删除
```

### 5. 智能提醒播报（v2.7.0）

触发提醒时通过 LLM 生成温暖、个性化的播报文案（≤20字），失败降级为通用文案。

### 6. 后台提醒守护

模块加载时自动启动 daemon 线程，每 30 秒检查到期事件和待办，到期则通过 `嘴巴.py` 语音播报。

## 数据文件

| 文件 | 格式 | 说明 |
|------|------|------|
| `todos.json` | JSON 数组 | 待办事项（id, title, due_date, due_time, completed, notified, created_at） |
| `events.json` | JSON 数组 | 日程事件（id, title, date, time, repeat, notified, created_at） |

## 配置

`模型.json` 中的 `use_smart_reminder` 开关（默认 true）控制智能播报文案。
