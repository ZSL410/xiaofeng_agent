# v3.11.1 — 天气类问题路由误判修复

> **日期**：2026-08-16 ｜ **类型**：🐛 路由修复

## 背景

用户问"今天天气怎么样"，晓风回复"没有查到记录"而非自然聊天。

## 根因

"今天天气怎么样" **不命中任何确定性预路由**，落入 3b 路由；3b 判为 `query` + `target=null`，
按既有降级策略**默认走财务查询** → 查询无记录 → "没有查到记录"。

同时存在一个隐蔽问题：`这个月下雨多吗` 命中 v3.11.0 分析预路由的
`(本月|这个月)...多吗` 模式 → 被误判为对比分析（`run_analysis`），同样答非所问。

两处都缺**天气关键词排除**。

## 变更内容（`脑.py`）

### 1. 分析预路由排除词扩展

`_ANALYSIS_EXCL_RE` 追加天气关键词：
`天气/天气预报/气温/下雨/下雪/晴天/阴天/多云/刮风/温度/降温/升温/台风/雷雨`

→ 修复"这个月下雨多吗"被分析预路由劫持。

### 2. 新增天气 → 聊天确定性预路由（v3.11.1）

在分析预路由之后新增 `_WEATHER_RE` 触发 + `_WEATHER_EXCL_RE` 排除：

- **触发**：`天气/天气预报/气温/下雨/下雪/晴天/阴天/多云/刮风/温度/降温/升温/台风/雷雨`
- **排除**：`花了/消费/记账/买了/付了/支出/费用/报销/预算/金额/多少钱/任务/待办/会议/提醒/日程/记住/记一下/帮我记/记得/删除/删掉/取消`

命中 → `_handle_chat(user_input, short_term)` 直接走聊天（7b 自然回应）。
排除词保证 `下雨天花了20打车`（财务记账）等强意图不被劫持。

### 3. 3b 路由聊天触发词扩展

`_ROUTE_PROMPT_3B` 的 chat 触发词追加天气类关键词，作为 LLM 层的第二道防线
（预路由已确定性兜底，此改动用于预路由漏网的表达变体）。
