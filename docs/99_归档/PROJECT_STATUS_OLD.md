### v3.5.0 (2026-06-22)

**🧠 规律遗忘机制 — 记忆衰减与用户反馈闭环**

> 数据提炼引擎发现的规律不会永远留存。v3.5.0 新增遗忘机制：30 天未触发的规律自动衰减置信度，用户明确拒绝的规律立即降权，低于阈值自动清除。配合正向反馈（boost），形成完整的「发现→确认→巩固/遗忘」记忆生命周期。

**核心改动（`记忆引擎.py` — 新增 3 个函数）：**

- **`decay_patterns(now_date=None)`** — 每周衰减检查
  - `last_triggered > 30 天`：每周 confidence -= 0.12
  - `confidence < 0.3`：自动删除
  - 更新 `last_decay` 时间戳防止重复执行
  - 返回 `{"removed": N, "decayed": N, "kept": N}`

- **`reject_pattern(content_substring)`** — 用户拒绝时立即降权
  - 匹配 content/from/to 字段中包含关键词的规律
  - 设置 `rejected = True`，confidence 立即 -0.30
  - 返回 `{"affected": N, "message": "..."}`

- **`boost_pattern(content_substring)`** — 用户确认时提升置信度（反向操作）
  - 清除 `rejected` 标记，confidence +0.10（上限 0.95）
  - 更新 `last_triggered` 为当天日期

**增强 `数据提炼.py`：**

- 新创建的 pattern 自动注入 `last_triggered`（当前日期）和 `rejected: false`
- 与旧模式合并时保留已有的 `rejected` 状态（避免覆盖用户反馈）

**集成 `脑.py`：**

- **启动时每周衰减**：新增 `_try_weekly_decay()`，检查 `last_decay` 字段，≥7 天时自动执行
- **用户拒绝意图处理**：正则匹配 `不用X` / `不要X` / `拒绝X` / `取消X`
  - 内容 `len ≥ 2` 时调用 `reject_pattern()`
  - 匹配到规律时跳过 LLM 路由（避免额外对话噪音）
  - 短内容（如纯"不用"）放行到正常路由

**记忆生命周期：**

```
发现规律(refine) → 置信度 0.5-0.95
  ├─ 用户确认(boost)  → confidence +0.10, last_triggered 刷新
  ├─ 30天未触发(decay) → confidence -0.12/周
  ├─ 用户拒绝(reject)  → confidence -0.30, rejected=True
  └─ confidence < 0.3   → 自动删除(遗忘)
```

### v3.3.0 (2026-06-22)

**📊 数据提炼引擎 — 行为模式发现**

> 新增 `数据提炼.py` 模块，扫描历史待办和日程数据，自动提炼用户的重复行为模式。提炼结果结构化存入 `长期记忆.json`，为未来的主动建议和智能提醒奠定数据基础。

**新增文件：`00_核心主体/记忆/数据提炼.py`**

- `refine(verbose=True)` — 主入口函数
  - 加载待办和日程数据
  - 调用 `extract_patterns()` 提炼模式
  - 将结果合并写入 `长期记忆.json`（`patterns` + `last_refined` 字段）
  - 返回结构化结果 dict（`status`、`total`、`by_type`、`message`）
  - 支持独立运行测试（`python 数据提炼.py`）
- 三种分析维度：

| 类型 | 字段 | 说明 | 最低样本 |
|------|------|------|----------|
| `time_based` | content, time_range, frequency | 同一内容在相似时间段重复（60min窗口聚类） | ≥2次 |
| `interval` | content, interval_minutes, occurrences | 同一内容以固定间隔创建（±25%容差） | ≥3次 |
| `association` | from, to, frequency | 内容A创建后频繁跟随内容B | ≥2次 |

- 输出格式（存入 `长期记忆.json`）：
  ```json
  {
    "patterns": [
      {
        "type": "time_based",
        "content": "泡咖啡",
        "time_range": "08:00-09:00",
        "frequency": 3,
        "confidence": 0.80
      },
      {
        "type": "interval",
        "content": "喝水",
        "interval_minutes": 30,
        "occurrences": 4,
        "confidence": 0.80
      },
      {
        "type": "association",
        "from": "冥想",
        "to": "休息",
        "frequency": 2,
        "confidence": 0.70
      }
    ],
    "last_refined": "2026-06-22T12:00:00"
  }
  ```

**增强 `schedule_module.py`：**

- **新增 `extract_patterns()`**：扫描 `_load_todos()` + `_load_events()` 返回提炼模式列表
  - 内容归一化：去掉"我"前缀，统一表达
  - 时间聚类：`_cluster_values(minutes, window=60)` 辅助函数
  - 置信度计算：`time_based`: 0.5+频次×0.1, `interval`: 0.6+次数×0.05, `association`: 0.4+频次×0.15

**集成 `脑.py`：**

- 导入 `from 记忆.数据提炼 import refine`
- **每日自动提炼**：新增 `_try_daily_refine()` 函数，启动时检查 `长期记忆.json` 的 `last_refined` 字段
  - 当天已提炼过 → 跳过（避免频繁扫描）
  - 从未提炼或最后提炼日期不是今天 → 静默执行 `refine(verbose=False)`
  - 提炼失败不影响正常启动（异常被捕获并打印警告）
- **手动触发**：新增触发关键词 `提炼规律` / `分析习惯` / `分析模式` / `提炼数据` / `发现规律`
  - 触发时直接调用 `refine(verbose=True)` 绕过 LLM 路由层，输出详细分析结果

**版本号**：v3.2.1 → v3.3.0（次版本号升级：新增独立功能模块）

**核心改动（`脑.py`）：**

- **`_ROUTE_PROMPT_V2` 新增 `delete_reminder` 动作**（### 3）：
  - 示例："把两个小时的那个定时删掉" → query="两个小时"
  - 提取规则：去掉噪声词后的核心描述

### v3.1.0 (2026-06-20)

**🧠 LLM 路由层语义增强：语音识别容错 + 结构化参数提取**

> 路由层从简单意图分类升级为结构化参数提取引擎，具备语音识别偏差的容错理解能力。

**核心改动（`脑.py`）：**
- **`_ROUTE_PROMPT_V2`**：全新提示词，包含语音识别容错规则
  - "教"→"叫" 误识别容错（`"5分钟教我"` → 理解为 `"5分钟叫我"`）
  - 纯数字+信号词识别（`"38叫我"` → 当前小时:38 的绝对时间）
  - 语义兜底：即使缺少明确信号词，只要"时间+内容"整体语义完整即视为提醒
  - 注入当前时间上下文，支持绝对时间推算
- **结构化参数提取**：路由层直接输出 `time_offset`、`absolute_time`、`content`、`raw_text` 完整参数 JSON
- **`num_predict` 提升**：20 → 200，适应结构化 JSON 输出长度
