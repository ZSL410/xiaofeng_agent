# v3.12.2 — 情绪路由修复

> **日期**：2026-08-16 ｜ **类型**：🐛 修复 —— 情绪表达路由 + 关联查询兜底

## 背景

Phase 6 实测发现三处问题：

1. **"我今天心情很好"被路由到财务**——3b 路由器把它判为 `record`（target=mod）→ 财务模块
   `process_command` 返回"没听懂金额"，系统永远到不了聊天分支，情绪检测与情绪记忆都无法触发。
2. **情绪记忆未创建**——因路由错误，`add_dialogue_record` 从未被纯对话轮调用，强情绪建记忆逻辑（v3.12.1 已实现）无法生效。
3. **"咖啡和什么相关"返回空**——候选记忆若无已存储的 `related_ids`（关联网络尚未构建时），关联查询无结果。

## 修复内容

### `脑.py`

**Issue 1：情绪表达确定性路由到 chat**

- 新增预路由 **(K) 情绪表达 → chat**（置于所有工具预路由之后、3b 路由之前）：
  - 触发：含 心情/情绪/开心/难过/高兴/生气/焦虑/压力/伤心/兴奋/激动/紧张/累/困/疲惫/烦/沮丧/失落/惊喜/感动/真棒 等情绪词
  - 排除：搜索/查看/记住/删除/添加/提醒/日程/花了/消费/买了/多少钱/记账/天气/分析/和什么 等工具意图
    （"搜索开心""查看压力记录""今天很开心买了咖啡花了20"等混合意图不被劫持）
  - 命中即 `_handle_chat`，绕过 3b 路由器
- 3b 路由提示词 `_ROUTE_PROMPT_3B` 聊天触发词新增情绪表达类：心情很好/心情不错/心情不好/心情糟糕/
  心情一般/今天很开心/今天很累/今天很焦虑/最近压力很大/有点难过/有点伤心/今天真棒 → **必须判定为 chat**

**Issue 3：关联查询兜底**

- (J) 关联记忆查询调用 `get_related_memories` 时启用 `live=True` 实时兜底（见下）

### `记忆引擎.py`

**Issue 3：`get_related_memories` 实时兜底**

- `get_related_memories(memory_id, limit=None, live=True)` 新增 `live` 参数：
  该记忆尚无已存储关联（`related_ids` 为空）时，调用 `find_related_memories` 实时计算，
  保证"XX和什么相关"总有结果——即使关联网络尚未批量构建。
- `find_related_memories` 在记忆创建时（`add_memory_event`）仍正常调用（v3.12.0 已有），关联网络持续构建。

**Issue 2**：情绪记忆创建逻辑（v3.12.1 已实现）——路由修复后自然生效：
`_handle_chat` → `_record_dialogue_archive(is_tool_round=False)` → `add_dialogue_record` 检测强情绪 →
`add_memory_event(subtype=emotion)` 创建情绪记忆。

VERSION 常量 `3.12.1 → 3.12.2`。
