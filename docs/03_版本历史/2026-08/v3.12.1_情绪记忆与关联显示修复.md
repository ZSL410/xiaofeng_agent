# v3.12.1 — 情绪记忆与关联显示修复

> **日期**：2026-08-16 ｜ **类型**：🐛 修复 —— Phase 6 两处体验问题

## 背景

Phase 6（v3.12.0）落地后，实测发现两处问题：

1. **情绪只进对话归档、不进记忆库**——用户说"我今天心情很好"，`mood` 被正确写入 `对话归档.json`，
   但 `memory.json` 没有任何对应记录，导致「搜索开心」查不到情绪，情绪信息形同虚设。
2. **关联记忆显示混乱**——"咖啡和什么相关"输出 `「记账」关联：记账|记账|记账`，
   用的是无信息量的 `title`（"记账"），未展示真实内容与关联原因。

## 修复内容

### `记忆引擎.py`

**Issue 1：强情绪自动创建情绪记忆**

- `VALID_MEMORY_SUBTYPES` 新增 `"emotion"`（情绪记忆子类型）
- 新增强情绪集合 `_STRONG_MOODS = {开心, 难过, 焦虑, 生气, 兴奋}`——仅强情绪建记忆；平静/疲惫/专注/困惑 等弱情绪不建
- 新增 `_extract_emotion_content(text)`——从用户输入提取情绪描述短句（去时间/主语前缀 + 取首个分句），
  例："我今天心情很好" → "心情很好"、"最近压力很大，有点焦虑" → "压力很大，有点焦虑"
- 新增 `_create_emotion_memory(text, mood)`——调用 `add_memory_event(title="情绪", subtype="emotion",
  content=情绪短句, detail=原文, mood=mood, tags=["情绪", mood])`；失败静默降级不阻塞对话
- `add_dialogue_record` 新增参数 `is_tool_round=False`：纯对话轮（非工具轮）+ 用户 + 强情绪 → 自动创建情绪记忆；
  工具轮（"搜索开心"/"记账：…"）不创建，避免工具指令被误记为情绪表达

**Issue 2：关联记忆结构化返回**

- 新增 `_strength_label(strength)`——强度数值 → 中文标签（≥0.9 强 / ≥0.6 中 / 其余 弱）
- `get_related_memories` 增强：每条关联记忆在原记录副本上附加 `strength`（数值）、`strength_label`（强/中/弱）、
  `reasons`（关联原因列表），仍按强度降序

### `脑.py`

- `_record_dialogue_archive` 将 `is_tool_round` 透传给 `add_dialogue_record`（两处调用）
- 预路由 (J) 关联记忆查询显示重写：改用 `content`/`detail`（而非 title），并按强度标注 + 原因：
  ```
  「咖啡」关联记忆（按强度排序）:
  [中] 晚上买了根雪糕花两块钱，挺好吃的 - 原因：同实体:购物、同标签
  [弱] … - 原因：同标签
  ```
- VERSION 常量 `3.12.0 → 3.12.1`
