# v3.10.1 — 路由修复（观点/金额/自然日程表达）

> **日期**：2026-08-12 ｜ **类型**：🐛 路由 Bug 修复（Phase 1 实测暴露）

## 背景

v3.10.0 对话归档上线后，实测暴露 3 个路由问题（对话归档完整记录了错误行为）：

| 输入 | 实测错误 | 期望 |
|------|----------|------|
| 你觉得咖啡好喝吗 | 路由到财务查询（列出共 51 笔 540 元） | chat（闲聊） |
| 明天有个重要的会议 | 日程模块显示使用说明（未识别"有+日程词"） | 添加日程事件 |
| 今天买了咖啡豆 | 财务模块"没听懂金额" | chat（购物陈述，无金额不是交易） |

## 根因

1. **观点问题**：3b 路由的 chat 触发词不含"好喝/觉得/怎么样"等观点词，模糊输入默认落到财务查询。
2. **自然日程表达**：日程模块 `process_command` 只认"添加/创建/安排"等显式动作词，不识别"有+会议/任务"（无动作词）的日常表达。
3. **无金额记账**：3b 路由见"买了"即判 record+finance，不检查是否有金额，"买了咖啡豆"（无金额）被当成待记账交易。

## 变更内容

### 1. 3b 路由提示词（`脑.py` `_ROUTE_PROMPT_3B`）

- **chat 触发词补充**（v3.10.1）：好喝、好吃、好看、好听、好玩、怎么样、觉得、认为、你怎么看、你感觉
- **观点/评价类规则**（最高优先级）：含"你觉得/你认为/你感觉/你怎么看/好不好喝/好吃吗/怎么样" → **必须为 chat**（绝不是 finance/schedule），即使含"咖啡/买了"等财务词。例外：同时含"多少钱/花了多少/合计"等财务查询词（"你觉得上个月花了多少钱"）→ query
- **财务记账必须有金额**：仅当含明确金额（数字 + 元/块/块钱/角/毛，或中文数字金额）才判 record+finance。仅含"买了/消费/花了"但无金额 → chat（购物陈述，不是交易）
- 新增 7 个示例（观点 3 + 无金额购物 2 + 有金额记账 1 + 观点例外 1）

### 2. 确定性预路由（`脑.py` main 循环，v3.10.1，在 3b 路由之前）

沿用 v3.9.27/v3.9.31 的确定性预路由思路，3 类意图完全绕过 LLM：

| 触发 | 处理 | 示例 |
|------|------|------|
| **(E) 观点/评价类** | chat（`_handle_chat` 统一入口） | "你觉得咖啡好喝吗" → 7b 闲聊 |
| **(F) 无金额消费陈述**（买了/消费/花了 + 无金额） | chat（购物陈述） | "今天买了咖啡豆" → 闲聊，不再"没听懂金额" |
| **(G) "有+日程词"** | 日程模块 | "明天有个重要的会议" / "后天有个任务" / "下周一有个面试" |

- (E) 排除财务查询词（多少钱/花了多少/合计/开销/支出/花费/账单），不劫持"你觉得上个月花了多少钱"
- (F) 排除日程/记忆/查询/提醒词，`_contains_amount()` 检测金额（数字+货币词 或 中文数字金额），有金额即放行记账
- (G) 排除查询（什么/哪些/有没有/吗）、财务（支出/元）、提醒（记得/叫我）词，不误触"今天有什么安排"、"明天会议支出花了500元"、"提醒我有会议"

### 3. 日程模块（`schedule_module.py` `process_command`）

新增"有+日程词"自然表达解析（无显式动作词）：

- `有 + 会议/日程/安排/事件/面试/活动等` → 添加日程事件
- `有 + 任务/待办/事项/todo` → 添加待办
- 中间允许形容词修饰（`有.{0,10}?{日程词}`），自动提取日期（明天/后天/下周一）和标题（"重要的会议"/"任务"/"面试"）
- 无日期无时间 → 澄清："请问是什么类型的日程？"
- 排除查询/财务/提醒噪声，不误触"今天有什么安排"、"会议支出花了500元"、"提醒我有会议"

### 4. 新增辅助函数

- `脑.py`：`_contains_amount()`（金额检测）、`_handle_chat()`（纯对话统一入口，供预路由复用）
- `schedule_module.py`：`HAS_EVENT_WORD_RE` / `HAS_TODO_WORD_RE` / 噪声排除正则
