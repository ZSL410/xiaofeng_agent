# 技术栈

## Python 依赖

| 包 | 版本 | 用途 |
|----|------|------|
| `edge-tts` | latest | 文字转语音（Edge TTS） |
| `vosk` | latest | 离线语音识别 |
| `sounddevice` | latest | 麦克风录音 |
| `numpy` | latest | 音频数据处理 |
| `python-docx` | latest | Word 格式财务报告生成 |

安装：`pip install edge-tts vosk sounddevice numpy python-docx`

## Ollama 模型

| 模型 | 用途 | 大小 |
|------|------|------|
| `qwen2.5:7b` | 主模型：聊天、意图路由、时间解析 | ~4.7GB |
| `qwen2.5:3b` | 降级模型：路由超时时的快速备选 | ~2.0GB |

安装：`ollama pull qwen2.5:7b && ollama pull qwen2.5:3b`

## 离线语音模型

`vosk-model-cn-0.22` (~170MB) 需手动下载到 `00_核心主体/` 目录。

## WSL 运行要点

- `模型.json` 中 `ollama_host` 默认 `http://localhost:11434`（指向 Windows 宿主 Ollama）
- 音频播放自动检测：WSL → `cmd.exe /c start`，纯 Linux → `mpv`/`ffplay`
- 路径基于 `__file__` 的相对路径，跨平台自动适配
