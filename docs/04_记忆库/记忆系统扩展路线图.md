# 记忆系统扩展路线图

> 从 v3.7.0 被动→主动学习升级后的后续规划

## 路线图总览

```
v3.7.0（当前）          v3.8.0（计划）          v3.9.0（计划）          v4.0.0（远景）
─────────────────    ─────────────────    ─────────────────    ─────────────────
三文件分离架构      → 向量语义检索        → 关系图谱            → 主动预判引擎
LLM 语义提取        + SQLite 存储         + 正式事件总线        + 多模态记忆
分层 Prompt 注入    + 相似记忆检索        + 因果推理            + 自适应学习率
置信度衰减          + 本地 Embedding      + 冲突检测            + 习惯自动纠正
```

## v3.8.0 — 语义检索与持久化

### 目标
利用 `embedding` 字段实现基于语义的记忆检索，替换纯 JSON 文件存储为 SQLite。

### 计划事项

| 事项 | 描述 | 优先级 |
|------|------|--------|
| 本地 Embedding 模型 | 使用 `bge-small-zh` 或 `text2vec-base-chinese` 生成向量 | P0 |
| 向量相似检索 | `search_similar(query, top_k)` 接口 | P0 |
| SQLite 存储 | `SQLiteStorage` 实现 `MemoryStorage` 抽象类 | P0 |
| 自动关联发现 | 基于向量距离自动建立 `related_to` 关系 | P1 |
| 语义去重 | 用 embedding 替代字符相似度去重 | P1 |

### 技术选型参考

```python
# 候选本地 embedding 方案
# 方案 A: sentence-transformers (CPU 友好)
from sentence_transformers import SentenceTransformer
model = SentenceTransformer('BAAI/bge-small-zh-v1.5')

# 方案 B: Ollama embedding API
# POST /api/embed  model: "nomic-embed-text"
```

## v3.9.0 — 关系图谱与事件系统

### 目标
建立记忆之间的显式关系网络，实现正式的事件发布-订阅系统。

### 计划事项

| 事项 | 描述 | 优先级 |
|------|------|--------|
| 关系类型扩展 | `temporal` / `causal` / `semantic` / `hierarchical` | P0 |
| 图谱构建器 | 自动分析 `related_to` 构建关系图 | P0 |
| EventBus 实现 | `on_pattern_formed` / `on_pattern_decayed` / `on_fact_confirmed` 正式事件 | P0 |
| 因果推理 | 基于 `association` 类型 pattern 推断因果链 | P1 |
| 冲突检测 | 新旧事实冲突时提示用户确认 | P1 |
| 图谱可视化 | 简单的记忆关系网络可视化（ASCII/HTML） | P2 |

### 事件系统设计预览

```python
class MemoryEventBus:
    def subscribe(self, event_type: str, callback): ...
    def publish(self, event: MemoryEvent): ...

# 使用示例
bus.subscribe("on_pattern_formed", lambda e: print(f"新习惯形成: {e.data}"))
bus.subscribe("on_pattern_decayed", lambda e: suggest_cleanup(e.data))
```

## v4.0.0 — 主动预判与多模态

### 目标
从"被动响应"升级为"主动预判"，支持多模态记忆。

### 计划事项

| 事项 | 描述 | 优先级 |
|------|------|--------|
| 主动预判引擎 | 基于习惯在时间窗口内主动推送提醒建议 | P0 |
| 自适应学习率 | 根据用户反馈自动调整 confidence 衰减速率 | P0 |
| 习惯自动纠正 | 用户否定某习惯后，自动发现替代模式 | P1 |
| 图像记忆 | 支持图片内容的记忆存储（OCR + 描述） | P1 |
| 音频记忆 | 语音备忘录转文字并索引 | P2 |
| 跨会话上下文 | 基于记忆自动恢复上次未完成的话题 | P1 |

### 主动预判示例

```
用户启动晓风（上午 8:15）
  → 引擎检测到 "每天 8:00-9:00 泡咖啡" pattern 置信度 0.85
  → 主动询问："早上好！要像往常一样设置泡咖啡提醒吗？"
  → 用户确认 → 自动创建提醒 + boost_pattern 置信度
```

## 技术债务与优化

### 待优化项

| 项 | 描述 | 目标版本 |
|----|------|----------|
| LLM 提取准确率 | 目前依赖 qwen2.5:7b，提取可能有遗漏 | v3.7.1 |
| 重复检测性能 | 当前 O(n) 遍历，大规模时需优化索引 | v3.8.0 |
| 衰减精度 | 每日一次乘性衰减在大跨度时欠精确 | v3.7.1 |
| 注入 Token 估算 | 当前基于字符的粗略估算，需更精确的 tokenizer | v3.8.0 |
