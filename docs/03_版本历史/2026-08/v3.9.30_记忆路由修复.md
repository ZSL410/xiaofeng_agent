# v3.9.30 — 记忆路由修复

> **日期**：2026-08-08 ｜ **类型**：🧠 Bug 修复（记忆相关意图路由）

## 背景

3b 路由器对记忆相关意图识别不足，导致"记住/记忆/搜索/身份问题"被误路由到财务或 clarify：
- "记住我叫霖" → record+finance → "没听懂金额"
- "查看今天的记忆" → query+finance → 显示财务数据
- "搜索咖啡" → clarify → "不太确定你的意思"
- "我是谁" → clarify

## 变更内容（`脑.py` `_ROUTE_PROMPT_3B`）

### 1. 身份类问题 → chat

chat 触发词补充：我是谁、我叫什么、我的名字、你知道我是谁吗、你知道我叫什么吗、记得我吗、你认识我吗。并注明"我是谁"不是记忆操作（7b 对话层可查询记忆）。

### 2. 记忆记录 → record + target:memory

- 规则：以"记住/记下/请记住"开头或包含"记住" → target **必须为 memory**（绝不是 finance），amount 为 null，content 填"记住"之后内容
- 即使含"喝/咖啡"等疑似财务词，以"记住"引导即记记忆非记账

### 3. 记忆查询 → query + target:memory

- 规则：含"记忆/回忆/回顾"且为查看类 → target **必须为 memory**，提取 time（今天→today / 最近→scope:latest / 昨天→yesterday）

### 4. 搜索 → search + target:memory（新意图）

- 触发词：搜索、查找、找一下、搜一下、有没有关于、相关记忆、记得吗、提一下
- keyword 填搜索关键词，target 必须为 memory

### 5. target 优先级

记住/记忆/回忆/回顾/搜索/查找/找一下 → **memory（最高优先级）**，例外：身份问题 → chat。

### 6. 示例补充

```
"我是谁" → chat
"记住我叫霖" → record+memory, content="我叫霖"
"记住我喜欢喝冰美式咖啡" → record+memory, content="我喜欢喝冰美式咖啡"
"查看今天的记忆" → query+memory, time="today"
"查看最近的记忆" → query+memory, scope="latest"
"搜索咖啡" → search+memory, keyword="咖啡"
"找一下关于咖啡的记忆" → search+memory, keyword="咖啡"
```

## 处理器实现（脑.py main 循环）

- **record + target:memory**：调 `add_fact(content)` 写入记忆
- **query + target:memory**：调 `get_memories(time_filter, limit)` 列出记忆（scope=latest 映射 last_week）
- **search**：调 `get_memories` 后按 keyword 过滤 title/content/tags 返回命中
- 意图枚举补充 `search`
