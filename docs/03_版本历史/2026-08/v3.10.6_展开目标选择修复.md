# v3.10.6 — 展开目标选择修复

> **日期**：2026-08-12 ｜ **类型**：🐛 展开目标选择（Hook H）

## 背景

`expand_dialogue` 目标选择用"最近记录"兜底，未按用户查询的关键词定位目标，导致"详细跟我讲一下你刚才怎么夸的我"返回无关对话（而非含"夸"的"夸我两句"记录）。

## 根因

原逻辑把查询清洗成短语（如"怎么夸的"）后做整串匹配，归档里很少有完全一致的记录 → 落回最近记录；且不区分 user/assistant 记录。

## 变更内容

### 1. 候选关键词提取（`脑.py` 新增 `_extract_expand_keywords`）

清洗展开触发词/指代词/助词后，按"特异性高→低"生成候选关键词：

| 生成方式 | 示例 |
|----------|------|
| 完整清洗结果 | 怎么夸的 |
| 按 怎么/如何/怎样/啥 切分后的实体段 | "怎么夸的" → **夸** |
| 渐进去尾助词/单字 | 怎么夸 / 怎么 |

### 2. 目标选择（Hook H 重写）

- 逐个候选关键词 `search_dialogue`，**命中即停**（不再只搜整串）
- **优先 user 记录**（用户想回忆自己说过的话）
- **跳过与当前查询相同的记录**（防止上一轮残留查询污染结果）
- 无关键词命中 → 回退**最近一条 user 记录**

### 3. DEBUG 日志

命中时输出：`[展开] 关键词匹配: '夸' → 找到记录: d2`。

## 自检结果
