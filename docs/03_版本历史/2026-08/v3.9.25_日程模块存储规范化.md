# v3.9.25 — 日程模块存储规范化

> **日期**：2026-08-05 ｜ **类型**：🎯 功能增强（存储标准化，与财务模块 v3.9.24 对齐）

## 背景

财务模块已在 v3.9.24 完成记录标准化（11/15 字段标准格式、时段标签、内容生成、排序规则、数据迁移）。日程模块（事件 + 待办）此前存在数据格式不一致的问题：

- 事件和待办字段结构不同
- 无统一 ID 字段（旧整数 ID 全局计数）
- 无时段标签（`period`）
- 无内容摘要字段（`content`）
- 时间字段命名不统一（事件 `time`，待办 `due_time`）
- 读取时无保证排序
- 部分待办无时间

## 变更内容

### 1. 统一记录结构（15 字段标准）

**事件（event）**：

```json
{
  "id": "schedule_event_20260802_1430_a3f8x2",
  "type": "event",
  "date": "2026-08-02",
  "time": "14:30",
  "datetime": "2026-08-02T14:30:00",
  "period": "下午",
  "title": "开会",
  "content": "下午开会",
  "detail": null,
  "location": null,
  "status": "pending",
  "repeat": "none",
  "notified": false,
  "created_at": "2026-08-02T14:30:00",
  "updated_at": null
}
```

**待办（todo）**（兼容旧字段 `due_date`/`due_time`/`completed`）：

```json
{
  "id": "schedule_todo_20260802_1800_b4g9y3",
  "type": "todo",
  "date": "2026-08-02",
  "time": "18:00",
  "datetime": "2026-08-02T18:00:00",
  "period": "晚上",
  "title": "买牛奶",
  "content": "晚上需要买牛奶",
  "detail": null,
  "status": "pending",
  "due_date": "2026-08-02",
  "due_time": "18:00",
  "completed": false,
  "notified": false,
  "created_at": "2026-08-02T18:00:00",
  "updated_at": null
}
```

### 2. 新增辅助函数

| 函数 | 说明 |
|------|------|
| `_get_period(time_str)` | 时间 → 时段标签（凌晨/早上/上午/中午/下午/晚上/深夜） |
| `_normalize_date(date_str)` | 统一为 `YYYY-MM-DD` |
| `_normalize_time(time_str)` | 确保 `HH:MM` 格式（空时间保留为空） |
| `_sort_records(records)` | date 降序 + time 升序 |
| `_generate_id(prefix, date, time)` | 生成 `schedule_{type}_{YYYYMMDD}_{HHMM}_{6字符}` |
| `_generate_event_content(period, title)` | `{period}{title}` → "下午开会" |
| `_generate_todo_content(period, title)` | `{period}需要{title}` → "晚上需要买牛奶" |
| `_migrate_schedule_to_standard_format(records, type)` | 迁移旧格式，不丢数据 |
| `_resolve_item_ref(items, ref)` | 按字符串 ID 或数字序号解析记录 |

### 3. 自动迁移 + 自动排序

- `_load_events()` / `_load_todos()` 加载时自动迁移 + 排序
- `_save_events()` / `_save_todos()` 保存时自动排序
- 模块加载时执行一次迁移（幂等，无旧数据时不写入）
- 迁移保留全部现有数据：标题、日期、时间、完成状态、通知状态、创建时间

### 4. CRUD 更新

- `_add_event()` / `_add_todo()` 写入全部标准字段
- `_delete_event()` / `_delete_todo()` / `_complete_todo()` 支持按字符串 ID 或数字序号操作
- `_list_events()` / `_list_todos()` 显示序号（替代原整数 ID）
- `query_schedule()` 结果统一按 date 降序 + time 升序
- `_complete_todo()` 同步更新 `status=done` 与 `updated_at`
- "显示今天的待办" 支持按日期过滤

## 排序规则

始终 **date 降序**（最新在前），同日 **time 升序**（最早在前）。

## 自检结果

| # | 测试 | 结果 |

| 2 | "添加任务买牛奶" → 待办含全部字段，content="需要买牛奶" | ✅ |
| 3 | 事件排序 date 降序 + 同日 time 升序 | ✅ |
| 4 | 待办排序 date 降序 | ✅ |

| 6 | "显示今天的待办" 只显示今天 | ✅ |
| 7 | "删除待办1" 按序号/字符串 ID 删除 | ✅ |
