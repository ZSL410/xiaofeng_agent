# v3.1.3 — 修正机制重写

**日期**：2026-06-22  
**类型**：Bug 修复  
**版本**：v3.1.2 → v3.1.3

## 变更摘要

修复用户纠正提醒时间时"越改越错"的 bug。重写 `modify_last_reminder` 使其始终以当前时间为基准重新解析纠正文本。

## 核心改动

### `modify_last_reminder()` 重写

- 删除最近一条待办后，从 `raw_text` 重新解析时间
- 三级时间重解析链：LLM → 正则(含过期验证) → 路由层参数降级
- 所有时间计算以 `datetime.now()` 为基准
- 无法提取时间时返回 `⚠️ 请重新输入正确的时间`

### LLM 提示词强化

- `_TIME_PARSE_PROMPT` 规则 2：`⚠️ X 始终是分钟数, 不是小时!`
- 新增规则 8：纠正文本"不是X是Y"提取 Y，忽略 X
- `_ROUTE_PROMPT_V2`：`time_offset` 规则增加同样警告
