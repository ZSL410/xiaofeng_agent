# v3.8.5 — 路由提示词精简与去重

**日期**：2026-07-23  
**类型**：重构 (refactor) — 无功能变更  
**影响范围**：`00_核心主体/脑.py` — `_ROUTE_PROMPT_V2`

## 变更动机

审计发现路由提示词存在严重的规则重复，同一概念在多处重复声明：

- 删除优先规则：6 处
- 否定词规则：2 处（含重叠示例）
- 误判纠正：独立 section（内容已被其他规则覆盖）
- 版本标记：v3.8.4 / v3.8.2 嵌入 prompt 头

这种重复不仅在 LLM 的有限上下文中浪费 token，更重要的是**多个版本的相同规则相互竞争注意力**，导致 LLM 在"删除今天的财务数据"等边界案例上仍可能优先匹配"财务"而非"删除"。

## 变更内容

### 删除优先规则：6 → 1

| 旧位置（6处） | 处理方式 |
|-------------|---------|
| 🚨 删除关键词优先规则 | **保留**（合并进否定例外） |
| ⚠️ 优先级规则 #1 | 改为简短引用（1行） |
| 财务 header | 移除整个 header |
| 财务 常见误判纠正 | 移除（查询词白名单已覆盖） |
| 决策链 step 1 | 压缩为 1 行 |
| 决策链子条款 | 合并至 🚨 规则 |

### 否定词规则：2 → 1

移除 🚨 规则中重复的否定例外说明（"先检查否定词...见下节"），仅在 ⚠️ 否定词规则中保留完整定义。🚨 规则中保留一行简短例外声明。

### 其他精简

| 变更 | 旧 | 新 |
|------|-----|-----|
| 版本标记 | `(最高优先级，v3.8.4)` | `(最高优先级)` |
| 财务 header | `（⚠️ 删除意图优先...）` | 无 header 备注 |
| 常见误判纠正 | 独立 block | 移除 |
| 决策链 | 9 行 + 子条款 | 3 行 |
| 优先级规则 | 3 条详细规则 | 3 条简短引用 |
| 财务分段 | 3 段带长示例 | 3 段带短例 |

### 字数对比

|------|-----|-----|------|
