# v3.7.3 — 路由提示词精简优化

**日期**：2026-07-12  
**类型**：优化 (optimization)  
**影响范围**：`00_核心主体/脑.py` — `_ROUTE_PROMPT_V2` + `_route_intent()`

## 变更动机

路由提示词 (`_ROUTE_PROMPT_V2`) 经过多个版本的迭代追加，累积了大量冗余内容：
- 重复的信号词列表（明确 + 容错分列）
- 重复的置信度示例（每个工具 2-3 个示例）
- 重复的 JSON 输出示例（高/低置信度分开写）
- 已被代码 fallback 处理的 `ask_clarify` / `confirm_response` 示例
- 与提示词主体内容重复的 `{tool_descriptions}` 注入

这导致提示词膨胀到 ~120 行 / ~2400 字符，压缩了本地模型 (qwen2.5:7b) 的上下文窗口。

## 变更内容

### 提示词精简
| 指标 | 旧版 | 新版 | 变化 |
|------|------|------|------|
| 行数 | ~120 行 | ~42 行 | -65% |
| 中文字符 | ~1500 | ~497 | -67% |
| 估算 token | ~1500-1800 | ~581 | -62% |

### 删除内容
- **重复信号词列表**（明确/容错分列 → 合并为一行）
- **重复置信度示例**（每档 2 个 → 1 句概括）
- **重复 JSON 示例**（8 个 → 6 个，去掉高/低置信度分开、去掉 ask_clarify/confirm_response）
- **`{tool_descriptions}` 占位符及对应代码**（TOOLS 循环 + `.format()` 参数）
- **版本标记**（"⭐ 新增" / "⭐ v3.2.0 新增"）

### 保留内容
- 6 个工具的完整路由规则（add_reminder / correct_reminder / delete_reminder / manage / 财务 / 聊天）
- 语音识别容错："教我"→"叫我"
- 参数提取规则（time_offset / absolute_time / content / query）
- 置信度评估指南（3 档）
- 每种工具 1 个代表性 JSON 示例
