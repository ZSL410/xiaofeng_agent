# v3.1.1 — 确认-修正机制

**日期**：2026-06-21  
**类型**：新功能  
**版本**：v3.1.0 → v3.1.1

## 变更摘要

路由层新增置信度门控：低置信度解析不再盲目执行，而是先向用户确认。同时支持用户纠正错误解析。

## 核心改动

### `_ROUTE_PROMPT_V2` 增强
- 所有输出格式新增 `confidence`（0-1）和 `explanation` 字段
- 新增 `correct_reminder` 动作类型

### 确认状态机
- `confidence < 0.6` 且 `action == "add_reminder"` → 拦截确认
- 确认回复：是/对 → 执行；不是/不对 → 取消
- 修正模式：`不是X是Y` → 删除旧+创建新

### 日程模块
- 新增 `delete_last_reminder()` 和 `modify_last_reminder(new_params)`
