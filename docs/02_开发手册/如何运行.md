# 如何运行

## 前置条件

1. Python 3.8+
2. Ollama 已安装并运行（`ollama serve`）
3. 已拉取所需模型：`ollama pull qwen2.5:7b && ollama pull qwen2.5:3b`
4. Python 依赖已安装：`pip install edge-tts vosk sounddevice numpy python-docx`
5. （可选）Vosk 中文模型下载到 `00_核心主体/`

## 启动晓风

```bash
cd /path/to/xiaofeng_agent
python 00_核心主体/脑.py
```

## WSL 环境

确保 `模型.json` 中 `ollama_host` 指向 Windows 宿主机的 Ollama 服务：
```json
{
    "ollama_host": "http://localhost:11434"
}
```
若 Ollama 与 Python 在同一系统，设置 `"ollama_host": null` 回退到 CLI 子进程。

## 交互命令

| 输入 | 说明 |
|------|------|
| 直接输入文字 | 聊天 / 工具指令 |
| `v` | 5 秒录音，Vosk 离线识别 |
| `退出` | 关闭程序 |
| `提炼规律` | 手动触发数据提炼 |

## 环境变量

| 变量 | 说明 |
|------|------|
| `DEBUG=1` | 启用日程模块详细扫描日志 |
